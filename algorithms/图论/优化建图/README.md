# 优化建图 · 路线

用数据结构结点代替区间连边: 单点连区间、区间连区间, 边数从 O(n²) 压到
O(n log n), 然后跑最短路 / SCC / 2-SAT。左程云课里叫"三种优化建图"的那批。

## 顺序

基础: 拆点、分层图、虚点(超级源汇) —— 手法层, 写几道例题就有手感
核心: 线段树优化建图 —— 出边树加入边树各一棵, 经典题 CF786B Legacy;
内存紧就换动态开点版
然后: 2-SAT 优化建图(线段树优化蕴含边, 配 SCC) 和 2-SAT 前缀优化建图
最后: 主席树优化建图(历史版本连边)、CDQ 优化建图(时间维分治连边)

## 入库形态

应用件流水线: 每个套路一篇组装范例(完整例题代码加关键行注释)。
对拍不强求; 真要验, 暴力参照系就是朴素 O(n²) 连边版。
差分约束和同余最短路在最短路问题\ 那边, 不在这。
