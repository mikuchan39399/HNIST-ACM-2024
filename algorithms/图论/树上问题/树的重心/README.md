# 树的重心

> `centroid.h` · 普通重心 / 整数点权扩展

做点分治、平衡拆分：**删一个点，让最大的剩余连通块尽量小**。令 $\mathcal{C}(u)$ 为删除 u 后的真实连通块集合，$w_x$ 为点权：

**最小化最大剩余块权和**

$$M(u)=\max_{C\in\mathcal{C}(u)}\sum_{x\in C}w_x$$

模板返回使 M 最小的全部点。普通重心取每个点权为 1；单点树删除后无块，约定 $M(1)=0$。

## 普通重心的性质

- 每个剩余块至多有 $n/2$ 个点。重心存在，至多两个；两个时相邻，连边把树分成等大两半。
- 答案与 DFS 根无关。某侧点数超过一半，就朝该侧走，直到所有侧都不过半。
- 点分治每次删重心，子问题至多减半，分治深度为 $O(\log n)$。

单位点权、单位边长时，重心也最小化到所有点的距离和。沿边从 u 走向 v，v 侧有 s 个点，则

**距离和的换根差值**

$$F(v)-F(u)=n-2s$$

> **分清目标** “最远距离最小”是中心，“删点最大块最小”是重心，不可互换。

## 点权扩展要分清目标

非负点权可按权和讨论平衡，零权可能带来更多并列解。若点权表示需求量，距离和目标为

**按需求量加权的距离和**

$$F(u)=\sum_x w_x d(u,x)$$

单位边长下跨边变化为 $W-2S$，W 为总权，S 为目标侧权和。非负点权、正边权下，重心也最小化该距离和；零边权可能增加距离和的最优点。

> **负点权** 模板仍按 M 的定义比较真实块；半权平衡、距离和最优、点数减半都不能直接套用。

| 输入 | 全部最优点与 M |
|---|---|
| 六点链，点权全 1 | 中间两点，3 |
| 六点链，点权全 0 | 六个点，0 |
| 两点相连，点权均为 -1 | 两个点，-1 |
| 单点，点权为 -7 | 唯一顶点，0 |

## 接口与易错点

先 `init(n)` 恢复默认点权，再写 `pt[1..n]`，最后 `build(g,n)`。

| 成员或接口 | 含义 |
|---|---|
| `centroids` | 全部最优点，编号升序 |
| `min_max_part` | 最大剩余块权和的最小值 |

不调用 init 时保留已有点权；若点权数组容量不足，build 会整体重置为 1，因此先完成初始化再填点权。

以 1 为 DFS 根，比较各儿子的 `sz[v]`，非根还比较父侧 `total-sz[u]`。

> **空块不是零权块** 根没有父侧，不能塞入一个值为 0 的空块；真实块权为 0 则仍须比较。

> **输入与边界** `n>=1` 的无向连通树，边权不参与计算。权和须在 `LL` 内，递归深度受栈限制。返回 c 个点时，时间为 $O(n+c\log c)$，空间为 $O(n)$；零权、负权时 c 可达 n。
