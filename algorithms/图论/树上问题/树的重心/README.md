# 树的重心

[返回树上问题](../README.md) · [树的直径](../树的直径/README.md) · [树的中心](../树的中心/README.md)

## 它衡量什么

重心衡量删掉一个点后，剩下的树分得是否均衡。对普通无权树，令 `M(u)` 为删除 u 后最大连通块的点数，重心就是使 `M(u)` 最小的点，也等价于每个剩余块不超过 `n / 2`。基础定义见 [OI Wiki：树的重心](https://oi-wiki.org/graph/tree-centroid/)。

这里衡量的是连通块大小，而不是到最远点的距离。树的中心负责最远距离，重心负责拆分平衡，两者可能是不同的点。

## 普通树的性质

以下默认每个点权为 1。

1. **一定存在，至多两个。** 如果有两个，它们相邻，删掉它们之间的边恰好分成两个大小为 `n / 2` 的部分。
2. **任选哪个点当 DFS 根，答案都不变。** DFS 根只决定如何计算子树大小，不改变删点后实际出现的连通块。
3. **沿过大的连通块走，可以找到重心。** 若某侧超过一半，就向该侧移动；反向一侧随即小于一半。最终停在没有过大块的点。
4. **重心使到所有点的距离总和最小。** 无权边下，沿边从 u 走向 v，若 v 侧有 s 个点，距离总和改变 `n - 2s`。存在超过一半的方向时可以继续减小总和，到重心则没有下降方向。
5. **适合作点分治的分治点。** 删除重心后，每个递归子问题至多原规模的一半，分治深度为 O(log n)。若每层总处理量 O(n)，总时间就是 O(n log n)。

“最多两个”和“一半”都依赖这里的权重语境，不能直接套到本库允许负点权的扩展定义上。

## 本库的点权扩展

[树的重心.cpp](树的重心.cpp) 对应 `centroid.h`。`pt[u]` 是点权，默认 1；模板实际最小化的是

`M(u) = max { 删除 u 后，每个真实连通块的点权和 }`。

`centroids` 按编号升序保存全部最优点，`min_max_part` 保存最优值。若 n=1，删点后没有任何块，本库约定 `M(1)=0`。

点权非负时，可以使用加权平衡的思想，把点数换成权和；零权会引入更多并列答案。若权值是需求量，距离总和应相应改成 `sum(pt[x] * dist(u, x))`，跨边变化是 `W - 2S`，W 为总需求、S 为目标侧需求。

点权可以为负时，本模板计算的是上述删点优化问题。此时“某块至多总权一半”、经典距离和最小化以及点分治规模减半的保证都不再直接适用。即使找到这个扩展意义的最优点，剩余块的结点数也可能很大。

几个边界例子：

| 输入 | 全部最优点与最优值 | 说明 |
|---|---|---|
| 六点链，全 1 点权 | 中间两点，值为 3 | 普通重心 |
| 六点链，全 0 点权 | 六个点，值为 0 | 答案可以超过两个 |
| 两点相连，点权均为 -1 | 两个点，值为 -1 | 不能用 0 压掉真实负块权 |
| 单点，点权为 -7 | 唯一的点，值为 0 | 使用无块时的约定 |

## 怎么计算与调用

以 1 为 DFS 根，先求 `sz[u]`，再比较每个儿子的 `sz[v]` 与父侧的 `total - sz[u]`。根没有父侧连通块，不能额外塞入一个值为 0 的空块；非根的父侧即使权和为 0，也是真实存在的块，仍须参与比较。

调用示例在源码尾部 Usage。先 `init(n)` 恢复默认点权，再填写 `pt[1..n]`，最后 `build(g, n)`。不调用 `init` 时，已有点权会保留；若点权数组不够大，`build` 会将点权整体重置为 1，应在设置点权前完成初始化。

输入必须是 `n >= 1` 的无向连通树。模板不读取边权，也不处理森林；权和须在 `LL` 内。DFS 为 O(n)，返回全部 c 个答案并排序使总时间为 `O(n + c log c)`，空间 O(n)。零权、负权下 c 可以达到 n，不能无条件把排序成本写成常数。

## 本库验证

`graph_check` 逐点删除，再独立遍历剩余连通块，核对全部答案与最优值；覆盖随机正/零/负点权，并保留上表的确定性用例。过去模板与暴力都把根的空块算成 0，现已共同修正，不能拿旧通过记录证明这个边界。具体环境与缺口见 [AI 验证明细](../../../../docs/verification/details.md)。
