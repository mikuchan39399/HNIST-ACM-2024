# 树的中心

[返回树上问题](../README.md) · [树的直径](../树的直径/README.md) · [树的重心](../树的重心/README.md)

## 它衡量什么

从点 u 到最远点的距离称为偏心距，记作 `ecc(u) = max dist(u, v)`。让偏心距最小的点是树的中心，最小值 `R = min ecc(u)` 是树的半径。它适合回答“设施放在哪，离最远的使用者也尽量近”。定义可参照 [OI Wiki：树的中心](https://oi-wiki.org/graph/tree-center/)。

本库实现的是**顶点中心**，只能从现有点中选择；不返回落在边内部的位置。直径是所有偏心距的最大值，半径是最小值，中心是达到最小值的点。

## 无权树的性质

1. **中心就是任意一条直径的中间点。** 若直径有 D 条边，D 为偶数时一个中心，D 为奇数时两个相邻中心。
2. **半径 `R = ceil(D / 2)`。** 对直径端点 A、B，任一点 u 至少离一个端点 D/2 那么远；取直径中间的顶点即可达到向上取整后的下界。
3. **直径可以有很多条，中心集合不变。** 取哪条直径都得到同一组中间点。
4. **中心作根，使树高最小。** 这里树高按根到最远点的边数算，不是子树数量或点数。
5. **逐层剥叶也能求中心。** 每轮同时删掉当前所有叶子，直到剩下一个或两个点；层数与最小树高相关。不能一次删一个叶子，否则会偏向任意顺序。
6. **中心不一定是重心。** 链 `1-2-3-4-5` 再在 2 上接三个叶子 6、7、8，中心是 3，重心是 2：一个优化最远距离，一个优化删点后的最大块。

注意向上取整：四点链的直径是 3，中心是 2、3，半径为 2，不能说中心到每个点都不超过直径的一半 1.5。

## 带权时哪些结论要改

本库支持非负整数边权，无权边按 1 计。固定一条直径 A-B，仍有

`ecc(u) = max(dist(u, A), dist(u, B))`。

因此可以算出所有点的偏心距，再直接找最小值。它同时处理权值不均匀和零权边，无需猜“路径上的第几个点”。

- **顶点半径不一定等于直径的一半向上取整。** 只有两个点且边长 10 时，两点都是顶点中心，半径为 10；若允许选边内部，中点才有半径 5。
- **严格正权时，顶点中心仍是一个或两个相邻点。** 连续中心位于直径的几何中点，沿边长度找离它最近的顶点即可；两个候选点并列时相邻。这里不能按路径结点个数取中间下标。
- **零权下中心可以超过两个。** 所有边权为 0 时，每个点都是中心、半径为 0。零权分支上的点还可能不在选中的那条直径上，却与其中点等距。
- **剥叶层数只适用于单位边长。** 边数少不意味着权和小，带权图不能照搬按度数剥叶的结果。
- **不支持负边权。** 负权下两次最远点搜索和端点代表最远距离的性质可能失效，不能仅把距离类型换成有符号数就宣称支持。

## 实现与接口

[树的中心.cpp](树的中心.cpp) 对应 `center.h`，类型为 `TreeCenter<G>`。实现做三次 DFS：先找直径端点 A，再从 A 求距离并找 B，最后从 B 求距离，与 A 的距离逐点取最大。只保留一张 `ecc` 表，不为两个端点各留一张完整距离表。

| 成员或接口 | 含义 |
|---|---|
| `build(g, n)` | 重建全部状态，返回半径 |
| `centers` | 全部顶点中心，编号升序 |
| `radius` | 顶点半径 |
| `ecc[u]` | u 到最远点的距离 |
| `end_u/end_v`、`diameter` | 一条直径的端点及长度 |

源码尾部提供无权和带权 Usage。输入须为 `n >= 1` 的无向连通树，点编号 `1..n`，路径权和不溢出 `LL`。单点树中心为自身、半径为 0。直接重复 `build` 即可多测复用。时间 O(n)，空间 O(n)，采用递归 DFS，深链需考虑评测栈。

## 常用场景与验证

中心适合服务站、广播源、最小高度根这类最坏距离目标。将两棵非负边权树用一条边连接时，连接两边的顶点中心能使新直径最小；计算公式见[直径 README](../树的直径/README.md)。若题目要求距离总和最小，则应看重心及其权重条件。

`center_check` 使用独立 Floyd 全源距离核对每点偏心距、半径、全部中心和直径端点。包含随机重标号树、零权分支、长权边、单点、奇偶链，以及 2000 点链/星的确定性检查。实际运行环境和未覆盖范围见 [AI 验证明细](../../../../docs/verification/details.md)。
