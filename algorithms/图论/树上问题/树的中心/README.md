# 树的中心

> `center.h` · 无权 / 非负整数边权

选服务站、广播源或最小高度根：**让最远的点尽量近**。

**偏心距与顶点半径**

$$\operatorname{ecc}(u)=\max_v d(u,v),\qquad R=\min_u\operatorname{ecc}(u)$$

中心是偏心距等于 R 的全部顶点。只在现有顶点中选，不返回边内位置；目标是距离总和时应考虑重心及点权条件。

## 无权树：取直径中点

- 中心就是任意直径的中间顶点，中心集合不随直径选择改变。
- 直径边数为偶数时一个中心，奇数时两个相邻中心。
- 以中心为根，树高最小；树高按根到最远点的边数算。
- 也可每轮同时剥掉所有叶子，直到剩一个或两个点，不能逐个随意删叶。

**仅无权树可直接使用**

$$R=\left\lceil\frac{D}{2}\right\rceil$$

四点链直径为 3，半径为 2。中心不一定是重心：链 `1-2-3-4-5` 在 2 上再挂三个叶子，中心为 3，重心为 2。

## 非负边权：比较偏心距

固定直径端点 A、B，逐点算

**非负整数边权**

$$\operatorname{ecc}(u)=\max\{d(u,A),d(u,B)\}$$

再取最小值，适用于不等边长和零权边。

| 边权 | 中心在哪里 |
|---|---|
| 严格正权 | 沿边长找直径几何中点，选最近顶点；并列时为两个相邻点 |
| 含零权 | 可能超过两个，也可在所选直径的零权分支上；全零树每点都是中心 |

> **易错** 不能按路径点数取中间下标，也不能照搬剥叶；负边权不适用。

两点间边长 10：两个顶点中心的半径均为 10；只有允许选边内中点时才是 5。

## 接口速查

`TreeCenter<G>`，三次 DFS 求端点与偏心距。

| 成员或接口 | 含义 |
|---|---|
| `build(g,n)` | 重建并返回半径，可直接重复调用 |
| `centers` | 全部顶点中心，编号升序 |
| `radius`、`ecc[u]` | 半径、u 到最远点的距离 |
| `end_u/end_v` | 一条直径的端点 |
| `diameter` | 直径长度 |

> **输入与边界** `n>=1` 的无向连通树，点为 `1..n`，无权边按 1 计；单点半径为 0。时间、空间均为 $O(n)$；递归深度受栈限制，路径权和须在 `LL` 内。
