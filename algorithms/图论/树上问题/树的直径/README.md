# 树的直径

[返回树上问题](../README.md) · [树的中心](../树的中心/README.md) · [树的重心](../树的重心/README.md)

## 它衡量什么

直径衡量树中相隔最远的两个点有多远。记唯一简单路径的权和为 `dist(u, v)`，直径长度为

`D = max dist(u, v)`。

无权树把每条边算作 1，长度是边数，不是路径上的点数。一棵树可以有多条直径，长度相同，端点和路径未必相同。定义与两种线性算法可参照 [OI Wiki：树的直径](https://oi-wiki.org/graph/tree-diameter/)。

本库允许 `u = v` 的零长度单点路径。因此单点树的直径是 0；有负边且所有非空路径都为负时，DP 版也返回 0。若题目要求至少经过一条边，需要另改 DP 初值与答案约定。

## 两种模板怎么选

| 模板 | 输入边权 | 输出 | 时间与空间 |
|---|---|---|---|
| [两次 DFS](两次dfs.cpp)，`diameterDfs.h` | 无权或非负整数权 | `len`、`end_u/end_v`、`path`、第二遍的父表 `pre` | O(n) 时间，O(n) 空间 |
| [树形 DP](树形dp法.cpp)，`diameterDp.h` | 无权或整数权，允许负权 | `build` 返回长度，`down[u]` 存向下最大路径权和 | O(n) 时间，O(n) 空间 |

两份源码尾部都有 Usage。`build(g, n)` 会重建状态，可多测复用；点编号为 `1..n`，`n >= 1`。输入须无向且无环，森林只处理点 1 所在的树，并不自动取所有连通分量的最大直径。所有路径加法须在 `LL` 内，递归深度受运行环境栈大小限制。

## 非负边权下的性质

1. **两次遍历就能找端点。** 从任意点出发找一个最远点 A，再从 A 找最远点 B，A 到 B 就是一条直径。树上路径唯一，DFS 累加权值即可，不需要为带权树使用 Dijkstra。
2. **一对端点代表所有点的最远距离。** 固定任意一条直径 A-B，对每个点 x 都有 `ecc(x) = max(dist(x, A), dist(x, B))`。因此求全体点的最远距离只需从两个端点各遍历一次。
3. **直径端点可不唯一。** 星形树的任意两个不同叶子都能组成直径。若边权严格为正且不止一个点，直径端点一定是叶子；存在零权边时，不能据此排除内部点。
4. **严格正权下，所有直径的几何中点相同。** 中点可以落在边内部。若只能选择顶点作为设施位置，还要按[树中心](../树的中心/README.md)的顶点定义选点；有零权边时应注意距离为 0 的多个点。

这些性质中的非负条件不能丢。比如链 `1 --(5)-- 2 --(-100)-- 3 --(6)-- 4`，从 1 出发最远是 2，从 2 出发最远是 1，两遍得到 5，真正最长路径却是 3-4 的 6。

## 算法为什么这样写

两次 DFS 利用上面的端点性质；第二次 DFS 顺便记录父点，再从 B 沿父表走回 A，得到 `path`。

DP 版枚举路径的最高点 u。经过 u 的最长路径由两条不同子树的向下链拼成，只保留最长、次长两条。负贡献不选，等价于允许某一侧停在 u。本库 `down[u]` 从 0 开始，因此也允许整条路径只含 u。

## 常用场景

- 题目问最远两点、树的最长传播时间或最长简单路径。
- 利用直径端点，把“每个点到最远点”转成两次遍历，进而求中心与半径。
- 合并两棵非负边权树：在 x、y 间接一条权为 w 的非负边，新直径为 `max(D1, D2, ecc1(x) + w + ecc2(y))`。跨树路径一定经过新边，因此最后一项由两侧最远点组成。
- 若连接点任意可选顶点，选两侧中心使跨树项最小，最小新直径为 `max(D1, D2, R1 + w + R2)`；无权树取 `R = (D + 1) / 2`。

直径描述最坏的两点距离；它不负责把删点后的块分小，也不保证距离总和最小。

`graph_check` 对两次 DFS 版核对非负权长度、端点和路径权和，对 DP 版额外核对含负权的长度。森林、深链和大规模并未由这组随机小树全面覆盖，详情见 [AI 验证明细](../../../../docs/verification/details.md)。
