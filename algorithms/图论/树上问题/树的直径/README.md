# 树的直径

> `diameterDfs.h` / `diameterDp.h` · 按边权选版本

求最远两点、最长传播时间，或把“每点到最远点”压成两次遍历。记 $d(u,v)$ 为唯一路径权和：

**最长路径，允许停在一个顶点**

$$D=\max_{u,v}d(u,v)$$

无权边长为 1，长度按边数算。允许单点路径，因此单点树、全负边树的答案均可为 0；若要求至少经过一条边，须调整 DP 初值。

## 选哪一版

| 模板与边权 | 结果 |
|---|---|
| `diameterDfs.h`：无权或非负整数权 | `len`、`end_u/end_v`、`path`、第二遍父表 `pre` |
| `diameterDp.h`：整数权，可含负权 | `build` 返回长度，`down[u]` 为向下最大路径权和 |

> **输入与边界** `build(g,n)` 重建状态。输入无向无环，点为 `1..n`；森林只处理点 1 所在分量。两版均为 $O(n)$ 时间、$O(n)$ 空间，递归深度受栈限制，路径加法须在 `LL` 内。

## 非负边权：抓住一对端点

从任意点找最远点 A，再从 A 找最远点 B，A-B 就是一条直径。对任意点 x：

**用端点表示每个点的偏心距**

$$\operatorname{ecc}(x)=\max\{d(x,A),d(x,B)\}$$

- 树上路径唯一，带权也可直接 DFS 累加，不必跑 Dijkstra。
- 直径与端点可不唯一。严格正权且不止一个点时，端点是叶子；有零权边时，内部点也可能是端点。
- 严格正权时，所有直径共用一个几何中点；中点可能在边内。只许选顶点时，转为求顶点中心。

> **负边反例** 链边权依次为 5、-100、6，从左端做两遍最远点只能得到 5，正确直径为 6。

## 负权：枚举路径最高点

DP 在每个 u 取来自不同子树的最长、次长向下链，相加更新答案。负贡献舍去，等价于某一侧停在 u；两侧都舍去就是长度 0 的单点路径。

## 接边合并两棵树

两树均为非负边权，在 x、y 间接非负权 w：

**连接顶点已确定**

$$D'=\max\{D_1,D_2,\operatorname{ecc}_1(x)+w+\operatorname{ecc}_2(y)\}$$

连接顶点可任选时，分别选两树中心，使跨树路径项最小：

**连接顶点可任选**

$$D'_{\min}=\max\{D_1,D_2,R_1+w+R_2\}$$

> **半径条件** 无权树半径 $R=\lceil D/2\rceil$；一般带权顶点半径不能直接用这个式子。
