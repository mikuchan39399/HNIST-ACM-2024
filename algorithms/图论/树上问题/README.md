# 树上问题

## 树的属性三件套

| 属性 | 关心什么 | 说明与模板 |
|---|---|---|
| 直径 | 最远两点之间的距离 | [定义、性质与两种实现](树的直径/README.md) |
| 中心 | 选哪个点，使到最远点的距离最小 | [顶点中心、半径与带权边界](树的中心/README.md) |
| 重心 | 删哪个点，使最大的剩余连通块最小 | [普通重心、点权扩展与点分治](树的重心/README.md) |

三份 README 解释意义与性质，源码尾部的 Usage 演示具体调用。中心看距离，重心看删点后的块，不能只凭名字互换。

其他树上模板包括 LCA、树链剖分与虚树；现役登记及笔记范围从[算法目录](../../../docs/features/catalog.md)查找。学习路线仍见[图论 README](../README.md)，个人状态见[图论进度](../../../docs/progress/图论.md)。
