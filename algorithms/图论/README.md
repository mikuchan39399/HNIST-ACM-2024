## 优化建图\(压轴题家族, 单独说)

用数据结构结点代替区间连边, 把 O(n²) 条边压到 O(n log n):
线段树优化建图(经典题 CF786B Legacy)、2-SAT 优化建图、前缀优化建图、
主席树优化建图、CDQ 优化建图。
做一道就知道, 这就是 seg × graph × dij 三件套流水线,
库的接口对齐在这里最值钱。
