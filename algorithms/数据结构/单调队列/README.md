# 单调队列

按顺序扫描，只保留仍可能最优的候选。`monoQueue.h` 提供滑窗最值 `mono_window` 和有限前驱 DP 骨架 `mono_dp`。

## 滑窗：先入队，再取答案

`mono_window(a,k,bad)` 接收 `a[1..n]`，忽略 `a[0]`，返回下标数组 `id[0..n]`。`id[r]` 对应窗口 `[r-k+1,r]`，最值为 `a[id[r]]`；未满窗口时下标为 0，不能当合法答案读取。

| 队尾弹出条件 | 窗口答案 | 同值保留 |
|---|---|---|
| `greater_equal<T>{}`：旧值 >= 新值 | 最小值，默认 | 最右下标 |
| `greater<T>{}`：旧值 > 新值 | 最小值 | 最左下标 |
| `less_equal<T>{}`：旧值 <= 新值 | 最大值 | 最右下标 |
| `less<T>{}`：旧值 < 新值 | 最大值 | 最左下标 |

## DP：先转移，再入队

`mono_dp(cost,k)` 返回 `f[0..n]`，示范递推为

$$f_0=0,\qquad f_i=c_i+\min_{\max(0,i-k)\le j<i} f_j$$

0 是合法初态，当前 i 不能成为自己的前驱；允许负费用。`cost={0,5,-2,4,1}, k=2` 得到 `{0,5,-2,2,-1}`。若题目有不可达状态，另设无穷大并跳过无效转移，不能照抄全零初值。

## 改题时盯住三处

- **队头过期**：改左边界。窗口左端必须不后退，否则丢掉的候选无法恢复。
- **队尾淘汰**：新候选不差，且不会更早过期，旧候选才可永久删除。关键字随查询变化时须重新推导。
- **取答案时机**：窗口包含当前点就先入队；只允许严格前驱就先查询。需要恢复路径时，同时确定平手保留哪个下标。

每个点入队一次、至多出队一次，总时间 $O(n)$，单次可能弹出 $O(n)$ 个点。输入不变，各次调用无共享状态。要求 `k>=1`；`k>n` 时无完整滑窗，DP 仍有合法前驱；空序列用 `{0}`。

滑窗工作数组与返回值约 `8(n+1)` B，DP 约 `12n+16` B，不含输入；按 n 分配，并非环形 $O(k)$ 队列。所有 DP 加法须在 `LL` 内。
