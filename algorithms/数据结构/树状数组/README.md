# 树状数组

[一维模板](树状数组.cpp) 提供 BIT 区间加与前缀/区间和, BITR 通过坐标镜像提供后缀/区间和;
[二维模板](二维树状数组.cpp) 提供 BIT2D 矩形加与矩形和。完整可运行 Usage 在源码尾部。

| 接口 | 含义 | 时间 |
|---|---|---|
| BIT/BITR.add(l,r,k) | 闭区间整体加 k, 单点取 l=r | O(log n) |
| BIT.pre(x) | 1..x 之和, pre(0)=0 | O(log n) |
| BITR.suf(x) | x..n 之和, suf(n+1)=0 | O(log n) |
| BIT/BITR.query(l,r) | 闭区间和 | O(log n) |
| BIT2D.add(x1,y1,x2,y2,k) | 闭矩形整体加 k | O(log n log m) |
| BIT2D.query(x1,y1,x2,y2) | 闭矩形和 | O(log n log m) |

构造后即为指定大小的全零数组, 无需再 init。多测调用 init(n) 或 init(n,m) 清空并设置本轮范围,
每个维度分别不得超过构造容量; 可以缩小后再增大。默认构造容量为 0, 不会随 init 自动扩容。
一维复位 O(n), 二维 O(nm)。所有修改/区间查询都要求合法非空范围, 下标从 1 开始。

一维的两张表维护差分与差分乘下标, 二维的四张表维护二维差分及两坐标的乘积项。
因此它们专用于加法与求和, 不直接支持区间赋值、最值或第 k 小。BITR 复用 BIT, 无需另维护一套实现。
负增量可用, 但增量取负、坐标乘积、表内累积、查询中间值都必须放得进 long long;
仅最终答案不溢出还不够, LLONG_MIN 不能直接作为增量。

一维每位置 16 B, 20 万约 3.2 MB; 二维每格 32 B, 2000×2000 约 128 MB,
另有边界填充和行 vector 开销。二维为稠密存储, 不适合直接分配巨大稀疏坐标域。

运行 `./scripts/run_checks.ps1 -Filter bit`。默认保留两类各 300 组朴素数组对拍,
新增一维 20 万长度/每轮 20 万次修改和查询的独立分块参照,
二维 2000×2000 在线矩形交集闭式答案与 10 万任意矩形修改/10 万查询的静态前缀和参照,
以及贴边、单格、正负大数抵消和大—小—大复位。全部自动进入普通和 sanitizer CI。
范围及实际运行证据见 [P08 验证记录](../../../records/verification/bit-20260906.md)。
