# 主席树

PersSegTree 的根由调用方保存。modify(old_root,l,r,tag) 返回新根, 旧版本仍可查询或继续分叉;
根 0 表示全零初始树。

| 接口 | 约定 |
|---|---|
| build(a) | a[1..m] 非空, 返回新基线根并把 n 设为 m; 追加到池中, 不清旧版本 |
| modify | 单点传 l=r, 只支持加法类可交换标记 |
| query/find | 不开结点, 查询累积祖先标记; 加法可维护 sum/max 等相容 Info |
| find_kth(plus,minus,k) | 多根计数相加减, 返回值域下标; 仅点修改计数版本 |
| clear | 清空全部版本并恢复哨兵, 保留容量与 n, 旧根全部失效 |
| set_n | 只改值域, 不清池; 改成不同值域后不能再访问旧域根 |

所有根都按当前 [1,n] 解释。多次 build 可以保留同值域的多个基线;
如果长度改变, 旧根不能拿到新值域里查询。多测通常先 clear, 再 set_n 或 build。

Info{} 的 len=0 表示合并单位元, 补上虚区间真实长度后其余字段须表示初始零值区间。
Tag 的叠加须满足本引擎的永久化契约, Info.apply 与合并须相容;
区间赋值等有顺序依赖的标记不适用。所有数值与中间运算仍须不溢出。

find_first/last 的 pred 要等价于“区间里存在合格点”, 例如 mx>=k。
若用 cnt>0, 必须保证逐点计数非负; 接口不会累计前缀。

find_kth 要求相加减后**每个位置**计数非负, 并且 1<=k<=总计数, 只有总计数非负不够。
范围加版本不能直接拿来做 kth, 因为 kth 不累积内部永久标记。

## 版本计数与预算

区间第 k 小用前缀版本相减：

$$H_{[l,r]}=H_r-H_{l-1}$$

树上点路径用根到点的计数版本。令 $p=\operatorname{lca}(u,v)$：

$$H_{u,v}=H_u+H_v-H_p-H_{\operatorname{parent}(p)}$$

根的父亲取空版本。各位置计数须非负，k 在总计数范围内。

预算按累计复制结点计算，查询和 find 不开点。点修改每次复制一条根到叶的路径；先开满一棵树需 $2n-1$ 个结点。区间修改按实际覆盖与复制量估算，不能直接套点修改预算。计数结点常为 32 B，sum/max 代数常为 40 B，另算根表与容量预留。
