# 常用 Info / Tag

> `SegTree<Info, Tag>` · 七组插件 / 普通树与动态树

**按修改选 Tag，再按询问选 Info。** 每行是一套完整搭配，复制所需文件，用其中的命名空间限定类型；同名 `Info`、`Tag` 不会互相撞名。

## 插件速选

| 命名空间 | 操作与询问 |
|---|---|
| [SegAdd](区间加区间和.cpp) | 区间加；和、最小值、最大值 |
| [SegAssignAdd](区间赋值加法与最值.cpp) | 区间赋值、加；和、最小值、最大值 |
| [SegAffine](区间仿射与平方和.cpp) | 区间乘、加、赋值；模意义的和、平方和 |
| [SegXor](区间异或与按位计数.cpp) | 区间异或；和、异或和、各位 1 个数 |
| [SegBinary](区间01赋值翻转与连续段.cpp) | 01 区间赋值、翻转；计数、最长连续 0/1 |
| [SegMaxSubarray](区间赋值与最大子段和.cpp) | 区间赋值；最大子段和、前后缀和 |

每组尾部都有完整 Usage。普通线段树写 `SegTree<Info, Tag>`，叶子用 `Info(value)`；SegLinear 用 `Info(value, index)`。数组从 1 开始，多测先 `init(n)` 再 `build(a)`。

## 标记复合：旧的在前，新的在后

`old.apply(next)` 表示先 old、再 next。先加 3 再赋值 0，结果为 0；先赋值 0 再加 3，结果为 3。空 Tag 是恒等操作。

仿射先做 $mx+a$，再做 $ux+v$，合成后为 $(um)x+(ua+v)$。若原和为 S、平方和为 Q，长度为 n，则

**仿射更新区间和**

$$S'=mS+an$$

**仿射更新平方和：右侧 S 为旧值**

$$Q'=m^2Q+2maS+a^2n$$

`Tag(0,x)` 即赋值 x，`Tag(1,x)` 即加 x；以上运算在选定模数下完成，Mod 无须素数。其他整数插件要求实际运算及累积标记的中间值不溢出 LL。

> **覆盖顺序** 新赋值覆盖旧操作；赋值 0 不能当无标记。平方和必须先使用旧 sum。

等差更新 `[l,r]` 的首项为 f、公差为 d，传 `Tag::progression(l,f,d)`。它化成 $di+(f-dl)$，因此区间被拆成多少个结点都使用同一个 Tag。

> **绝对下标** 等差更新转为 `k*i+b`，不能让每个覆盖结点从首项重新计算。

## 空段与动态树

`Info{}` 是合并单位元，len=0；不是任意长度的默认数组。七组均可用于完整 build 的普通树或动态树。

> **必须 build** SegBinary 的全零段连续 0 长度等于 len；SegLinear 要有真实下标和。这两组不能仅补 len。

其余五组支持动态树从全零虚区间起步。SegXor 的位数范围为 1..31，元素与掩码均小于 $2^{Bits}$，长度不超过 INT_MAX；按题缩减 Bits 可减少时间与空间。其树操作为 $O(Bits\log n)$，其余六组为 $O(\log n)$。

## 合并与查询的易错点

- **最值** 空段先判 len，负数最值不能被 0 抬高。
- **异或** 翻转第 b 位后，`cnt[b]` 变成 `len-cnt[b]`。
- **连续段** 同时存 0/1；跨界段由左后缀接右前缀。
- **最大子段** 子段非空，全负时取最大元素，不取 0。合并有左右顺序，不能交换孩子；区间加法不能只靠这四个和直接更新。

> **存在性判据** 找第一个达到阈值的点，可对最值插件传 `v.mx>=k`；不能把 `v.sum>=k` 当通用判据。

取模、chmin 与历史最值属于另外的势能修改场景，见相应专题文件；它们的剪枝与整段可更新条件不能替换为这里普通懒标记的恒 false / true。
