# 分块家族 · 路线

现状: 零存量。和线段树是互补的两种哲学: 均摊对递归。
资源: OI Wiki 的分块 (oi-wiki.org/ds/decompose) 和莫队 (oi-wiki.org/misc/mo-algo) 两节。

先学:
普通序列分块(单点/区间加查) —— 中高频, 是全家地基
莫队\ —— 普通 → 带修 → 树上, 引擎按 §3.5 第二档设计,
调度器和 add/remove 分开写

再学:
根号分治\ —— 和分块是一对思路
值域分块(配合回滚技巧)
树上分块\

最后:
块状数组\ 和已有的 块状链表\, 低频

不学: 莫队二次离线和 bitset 变体, 赛场上推导成本太高。
对拍暴力就用最笨的参照系: 每次操作全量重算。
入库流程照 计算几何\README.md。
