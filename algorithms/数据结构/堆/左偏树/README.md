# 左偏树

[普通版](左偏树.cpp) 管理多个可合并堆, 接口接收逻辑元素编号;
[可持久化版](可持久化左偏树.cpp) 接收并返回物理根句柄, 由调用方保存历史版本。
两者默认小根堆, `greater<LL>` 切换大根堆。

## 普通版

`init(n,a)` 创建 n 个独立堆, a 是 1-based 初值数组, 省略则全部为零。
`merge(x,y)` 合并所属堆, `insert(x,v)` 返回新逻辑编号, x 为 0 或死点时独立成堆。
`pop(x)` 弹出所属堆顶, `erase(x)` 删除指定点; `set_val/add_val` 保留逻辑编号但消耗新物理点。
同值时较小逻辑编号优先。pop/erase 返回剩余堆顶编号, 空堆为 0, 无效死点为 -1;
merge 同堆也返回 -1。死点编号不能代替所属堆的活点继续操作。

`get_top_id/get_top_val/get_size/get_heap_sum` 查询所在堆, `get_roots_id` 返回所有堆顶编号, 顺序不固定。
编号须为当前初始化后已分配的 1..n, 0 可作为空入口; 不支持任意越界编号。

操作分两个语义域:

- 单点域可用 get_val/set_val/add_val/erase, 配合 merge/insert/pop/add_all。
- 调用 heap_add 或正数 heap_mul 后, 只用堆级操作与堆顶/大小/和查询; 非根懒标记未下传,
  不再对受影响堆调用上述单点接口。add_all 仅维护全局偏移, 不造成这个限制。

构造参数: max_n 覆盖初始逻辑点加 insert 总次数, max_ops 按 insert/set_val/add_val 次数预留;
物理表分配 max_n+max_ops, 删除不回收, init 后重新使用。LL 物理点各字段加根列表预留约 64 B,
另有 deleted 位表与逻辑点 4 B 映射; 20 万逻辑点加 10 万操作预留约 20 MB。

所属堆查找使用迭代路径压缩, 连续换根可能产生线性父链, 不承诺单次 O(log n) 或 O(α(n))。
记 h 为本次父链长度; 左偏树合并沿右链递归 O(log P), P 是累计物理点数。
惰删点在以后到达堆顶时才清理, 单次 pop/erase/set_val 可能清理多个死点, 不能按一次合并估算。
所有偏移、标记乘积、元素和及中间值都须在 T 内。

## 可持久化版

根 0 表示空堆。`new_node(v,pay)` 创建独立点, `insert/merge/pop` 返回新版本根,
旧结点不改写; empty/size/top/sum/top_pay 查询不分配结点, top/top_pay 只用于非空根。
同值时不保证 payload 的返回顺序, 要求稳定排序时由调用方把次关键字纳入键及比较器。

共享版本甚至同一个根可以 merge, 语义是多重集合相加, 重叠元素会重复出现。
逻辑元素数必须在 int 内, 元素值与求和中间值必须在 T 内; 少量物理点也可能表示巨大逻辑集合。
`init()` 清池复用容量, 之前所有根失效。

`merge_raw(x,y)` 是原地建堆接口, 两个输入都可能被修改; 只能接独占且互不重叠的堆。
建立共享版本后不得用它修改共享结点, 也不能把同一根传入两次。普通 merge 没有这些独占限制。

LL 值与 int payload 每个物理点 36 B, 构造会分配整个预算。每次 insert 额外创建单点,
merge/pop 复制 O(log N) 条路径上的结点; 预算按累计复制量计算, 固定“每操作 40 点”不是任意规模的保证。
保留历史版本会持续增加池占用；先按全部操作的复制量估预算，再乘每点字节数，另算根表。
