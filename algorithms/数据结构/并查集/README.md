# 并查集

| 模板 | 维护什么 | 跳板 |
|---|---|---|
| [DSU](DSU.cpp) | 集合合并、连通性、集合大小 | `dsu.h` |
| [WDSU](WDSU.cpp) | 连通性以及同组两点的有向距离或取模关系 | `wdsu.h` |

**合并方向固定**: 第二个参数所在集合的根挂到第一个参数所在集合的根。根不是最小编号, 后续合并也可能改变它。find 用两遍迭代压缩路径, 不依赖递归栈; 单次仍可能走过整条父链, 不能把它当作最坏常数时间或带按秩合并的实现。

## 普通并查集

merge(u,v) 在两组不同时合并并返回 true, 已连通时返回 false。same(u,v) 判断连通, size(x) 返回整个集合的点数。sz 只在根处有效, 不直接读取非根的 sz[x]。

```cpp
#include "dsu.h"
DSU ds(200000);
ds.init(n);                 // n 不超过构造容量
ds.merge(1, 2);
ds.merge(3, 2);             // {1,2} 的根挂到 3
int root = ds.find(1);      // 3
int count = ds.size(2);     // 3
```

集合只合并, 不拆分或删除元素。路径压缩会改写父亲, 因而不能直接把此模板当作可撤销或可持久化并查集。

## 带权并查集

用势能 P 记方向，`merge(x,y,w)` 加入关系，`query(x,y)` 返回对应差：

$$P_x-P_y=w$$

两组尚未连通时可以整体平移其中一组, 让新等式成立; 已连通时直接忽略新声明, **不检查或覆盖矛盾约束**。

d[x] 存 x 到当前父亲的距离, 根处为 0。先调用 find(x) 后, d[x] 才是 x 到当前根的距离; 不同集合的根没有共同基准, 不能直接比较其 d。

- mod=0: 保存普通有符号距离, 反向查询互为相反数。
- mod>0: 保存 [0,mod) 内的余数, 适合奇偶或分类关系。反向关系是模意义下的相反数, 不一定是普通负数; mod=1 时所有已连通关系均为 0。
- 未连通时 query 返回 WDSU::INF。合法距离也可能恰好等于 INF, 判断连通必须用 same。
- 所有距离加减中间值仍须在 LL 内; 大模数不会自动避免求和或求差溢出。

```cpp
#include "wdsu.h"
WDSU ds(200000);
ds.init(n, 3);              // 当前测试使用三类关系
long long w = 2;            // 判矛盾前先把输入归一化到 [0,3)
if (ds.same(x, y)) {
    bool conflict = ds.query(x, y) != w;
    // 调用方根据 conflict 处理矛盾
} else {
    ds.merge(x, y, w);
}
```

## 容量与复位

构造参数决定容量, 点编号为 1..n。init(n) 只重置当前有效的 0..n, 不扩容, 可以先大后小再恢复到构造容量; 默认零容量对象只能复位为 0。WDSU 的 init(n,mod) 同时清空距离并切换模式, 省略模数等价于 mod=0; 不在保留旧关系时直接改 mod。

DSU 每点约 8 字节, WDSU 每点约 12 字节, 20 万点分别约 1.6 MB 和 2.4 MB。初始化为 O(n); 查找及其封装接口按实际经过的父链长度计时, 单次最坏 O(n), 额外空间 O(1)。
