# 字符串 · 学习路线

已有: 字典树×2(含可持久化)。这是全库最明显的短板之一, 按顺序补:

先学(高频):
字符串哈希\ —— 双模哈希加子串比较, 半天搞定, 回报最高
KMP\ —— 然后顺手学 Z函数\(扩展 KMP)和最小表示法
AC自动机\ —— 字典树加失配边, 学完字典树就能学

再学(中频):
Manacher\ —— 回文半径
后缀数组\ —— SA、height 数组、LCP 配 RMQ

最后:
后缀自动机\ 和 回文自动机\ —— SAM/PAM 都是大工程, 按 §3.5 第三档写自含式
序列自动机\ —— 子序列自动机, 很小, 半小时的事, 顺手写掉

不学: 后缀树、Lyndon 分解, 射程外。
入库流程照 计算几何\README.md。
