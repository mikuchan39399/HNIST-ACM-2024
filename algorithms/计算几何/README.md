# 计算几何 · 学习路线

全库最大的空白。原则一句话: 概念自己学, 实现可以协作, 正确性靠对拍 ——
整数精确暴力打浮点 eps 模板, 这是几何界公认最稳的验证方式。

资源:
OI Wiki 计算几何 (oi-wiki.org/geometry) 当主教材
cp-algorithms 的 Geometry 部分, 每篇带代码
紫书几何章, 精度处理的讲法没有替代品
练习: 洛谷题单搜"计算几何", 从 P2742 二维凸包起步

先学(覆盖区域赛 80% 的几何需求):
二维基础\ —— 点积叉积、极角排序、线段判交。这层必须逐行搞懂:
eps 约定、符号、退化全在这, 赛时出问题修的也是这层
凸包\ —— Andrew 单调链
多边形\ —— 有向面积、点在多边形内
平面最近点对\ —— 分治

再学:
旋转卡壳\、半平面交\、圆\(圆线交、圆圆交、公切线)、扫描线\(骨架已有)

不学: Delaunay/Voronoi、反演变换、三维大部分, 射程外。

每个专题的流程: 读 OI Wiki 对应节 → 基础层自己手写, 踩一次精度的坑 →
引擎入库(带 Usage) → 写整数暴力对拍 300 组 → 记坑位 → 配跳板 → §11 销账
