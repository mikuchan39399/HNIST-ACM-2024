## 整体二分

两种完整范式并列放在 `algorithms/杂项/离线算法/整体二分/`，都以 P3834 静态区间第 k 小为代表，复用 `Dcr` 与 `BIT`，采用 1-based 输入和答案。

- [整体二分_回滚.cpp](<../../algorithms/杂项/离线算法/整体二分/整体二分_回滚.cpp>)：`pbsRollback.h` → `PBSRollback::range_kth(n, q, d)`，当前左半值域统计、右侧扣减 k、递归前撤销 BIT。
- [整体二分_指针.cpp](<../../algorithms/杂项/离线算法/整体二分/整体二分_指针.cpp>)：`pbsPointer.h` → `PBSPointer::range_kth(n, q, d)`，固定有序 ins、全局指针调到 val <= mid、k 保持原排名。

调用方建立 `Dcr<int> d` 和统一的 `vector<Event> q`：前 n 项为插入，其后为询问；val 填离散排名，id 填答案编号。函数按值接收 q，不修改原事件表；不再需要原表时可传 `move(q)`。

两版均保留缺省 `E = Event`。一维可继续用默认事件调用 `range_kth`；自定义一维事件也可自动推导，但须提供原有字段。二维只保留公共 `type/val/k/id`，其余坐标自定，用 `kth(n, V, q, add, count)` 接外部二维 BIT。这里 n 是插入事件数，V 是离散值数量，ql/qr 始终是事件下标；内核返回排名，输出原值用 `d[ans[id]]`。完整一维和二维代码均在源码尾部 Usage。

`add(const E&, delta)` 负责给插入位置加减 1，`count(const E&)` 统计查询集合中的当前元素数；外部统计开始为空，正常返回时恢复为空。两个 lambda 之外不再拆分原事件循环、稳定划分和递归，方便继续理解算法。两份仍属固定内核加题目骨架，只支持静态第 k 小；带修改需要维护时序与正负事件，当前均未实现。

当前继续对照两版 BIT 状态和 k 的含义，学习状态仍为正在学；独立排序、边界及目标规模覆盖见 [对拍入口](<../../algorithms/杂项/离线算法/整体二分/对拍/parallel_binary_search_check.cpp>)。按本人选择不另配源码目录 README。
