# 打印比赛手册

先准备 Typst：放入 PATH，或把 typst.exe 放在 scripts 目录。然后在库根目录运行：

```powershell
./scripts/make_booklet.ps1
```

唯一正式 PDF 为 docs/booklet/output/zoi-booklet-print.pdf，配套 zoi-booklet-print.typ 放在同一目录。每次默认生成直接更新这一份，不再分普通版和 print 版；第 39 页保留 MIKU ♡ 页脚。默认 A4 横排三栏，带目录、页码和代码指纹；catalog 的顺序决定条目顺序，笔记会一并收录。

只看某一部分，或为双面打印安排较长条目从正面开始：

```powershell
./scripts/make_booklet.ps1 -Filter seg -OutFile .zoi-checks/codex-work/booklet-seg.pdf
./scripts/make_booklet.ps1 -SoloMin 90
```

筛选版不执行全库覆盖审计，预览用 OutFile 放入库内临时工作区，避免覆盖正式整本；赛前生成不带 Filter 的完整版本，并检查纸面排版。PDF 和配套 .typ 为生成物，不提交到 Git。

用 -OutFile 指定其他 PDF 路径时，配套 .typ 使用相同文件名并放在旁边；相对路径从库根解析，目录不存在时自动创建。

实现约定见 [维护说明](../maintenance/README.md)。

## 打印设置

目录后附有打印参数: A4 横向, 实际大小 / 100%, 每张纸 1 页 PDF, 双面短边翻转, 黑白保留灰度。正文为 6 pt, 先试印一页代码并核对清晰度与页边; 若打印机提示超出可打印区域, 检查预览后按需适配并再次试印

## 查阅与版式

封面带生成日期、收录范围和三步查阅提示: 定位模板、核对契约、按 Usage 组装。打印前先核对封面的日期与筛选范围。

页眉左侧用浅灰标签标出当前方向，中间是本页首个条目（续页延续原条目）；代码上方的信息条列跳板短名、行数和指纹。正文使用白底代码框，保持三栏和原代码字号。待补标记只用于真正的占位或空壳。

每个登记条目仍另起一页，方便单独抽换。-SoloMin 90 使达到阈值的正文及插件从奇数页起排，可能增加双面打印的空页；默认不补这些空页。筛选打印仍使用完整 catalog 解析依赖跳板。

## 模板变长后怎么办

正文会自动从当前栏流到下一栏，再增加页面，不会为了塞进一页而缩小代码字号。新增或加长模板后，重新运行 make_booklet.ps1 生成整本，目录、页码和总页数一起重算；脚本不是实时监听器，编辑源码后旧 PDF 不会自行更新。若抽换纸页，后续页码可能改变，建议同时替换目录或重新打印整本。

已在隔离版本中用连续编号的1200行代码验证跨6页分栏：行序完整、续页页眉正常，追加末尾条目也完整。正式手册和算法源码不受这次压力测试影响。
