# 打印比赛手册

在库根运行，或使用 VS Code 的 `zoi-booklet` 任务：

```powershell
./scripts/make_booklet.ps1
```

准备 Typst 0.15.1（本库验证版本）：放入 PATH，或把 typst.exe 放在 scripts 目录。中文字体使用 Noto Sans SC、Noto Sans CJK SC 或微软雅黑，脚本自动选本机可用字体；没有可用中文字体会报错。代码使用 Consolas 或 DejaVu Sans Mono。

唯一正式 PDF 是 `docs/booklet/output/zoi-booklet-print.pdf`，同目录保留同名 `.typ`。每次重建直接更新，保留第 39 页 MIKU ♡ 页脚，不再维护第二份正式版。PDF 为 A4 横向三栏，带目录、方向页眉、代码行数和指纹；生成物不提交 Git。

## 哪些内容会印进去

- **真实算法目录树决定章节，源码决定实现条目。** 扫描 `algorithms/` 的全部算法目录，已建与待建都进入目录和正文；只排除 `对拍/` 及隐藏工具目录。不用 catalog 或分类表作为目录收录名单。同目录多份实现分别进入目录，如左偏树的两个版本、平衡树的八份实现。
- catalog 决定现役源码/笔记身份、跳板短名和已有家族的优先顺序；未登记家族按路径排序。代数插件自动发现后回到所属目录，含 main 的例题不混入插件；独立源码仍按原 catalog 契约登记。
- **源文件同目录只要有 README.md，就自动附在算法后面。** 不需要改 catalog 或登记一张说明名单。
- 同目录有多份实现时，共享 README 只印一次，紧跟本次选中的最后一份实现。筛选只留下其中一份时，说明仍跟随它；共享说明会保留对其他版本的介绍。
- **每份代码、登记笔记和插件另起一页，页尾留作补写。** 长模板自动跨栏、续页，说明紧跟代码排完，下一份实现再换页。祖先标题跟随首个条目；目录与唯一同名源码合用标题，不重复列两次。
- 方向另起页，待建目录单独集中排，标题下留短线和间距，不逐目录占整张空白页，也不挤进已排模板的页尾预留。新增源码登记后自动获得独立页段，不需要手调页码。
- 不继承父目录或子目录 README。[路线图](../roadmaps/README.md)的长文字不入册，但对应算法目录仍入册；登记笔记仍照常打印。

Git 不保存真正空的文件夹。待建叶目录用 `.gitkeep` 保留，让队友克隆、压缩包和 CI 得到相同目录结构；它本身不打印。

树的直径两版共用一份说明，树的中心、重心各有一份；单调队列/栈和其他有 README 的模板也使用同一机制。是否给新模板写说明完全由用户决定，没有 README 就只印代码与自带 Usage。

## 说明怎么排版

目录页和正文标题共用按深度递减的样式：方向最醒目，家族其次，子目录逐层减小字号、收敛字重与颜色；目录每层缩进 6 pt。深层只限制最小字号，不截断目录深度，不会退回更大的默认样式。目录行保留独立间距，避免紧凑排版挤叠文字。

普通 Markdown 的标题、段落、粗体、行内代码、列表、表格和围栏代码会转成紧凑正文。说明标题不挤进算法目录；表格有浅灰表头，换页时重复表头，代码保持 6 pt，说明正文 7 pt。

入册说明面向赛场：写适用条件、关键性质、公式、接口、修改位置和易错边界。学习路线、对拍/CI 记录、维护与迁移历史留在仓库的对应文档里，不混进纸面速查。

公式用 `$x_i^2$` 写在行内，用 `$$…$$` 单独成块，也支持将两个 `$$` 各放一行。PDF 使用 New Computer Modern Math 数学字体，独立公式为 8 pt、浅灰底，分式、上下标与求和上下限按数学结构排版。反引号和代码围栏内的美元符号保持原文。

支持常用 TeX 子集：`_`、`^`、`\frac{a}{b}`、`\sqrt{x}`、`\sum`/`\prod`、`\min`/`\max`、`\log`/`\ln`、关系与箭头，以及 `\operatorname{lca}`、`\mathrm{ecc}`、`\mathcal{C}`。`\left`/`\right` 可配圆括号、方括号、绝对值或取整符号，按内容高度伸缩。可用命令以转换器白名单为准；不支持宏、矩阵或完整 LaTeX 环境，未知命令、错误括号或未闭合公式直接报错。新增写法先筛选预览，不能靠构建成功代替检查公式含义。

纸上链接显示可读标题，完整目标保留在仓库 Markdown。不执行嵌入 HTML、图片或 Typst 代码；复杂 Markdown 的原始符号可能按文字保留。未闭合围栏、表格列数不一致直接报错，避免静默漏内容。

## 筛选预览与双面打印

```powershell
./scripts/make_booklet.ps1 -Filter diameter -OutFile .zoi-checks/codex-work/diameter.pdf
./scripts/make_booklet.ps1 -SoloMin 90
```

`Filter` 匹配完整目录路径、跳板名或算法文件名；可以单独预览尚无源码的目录，保留其祖先层级。筛选必须显式指定其他输出位置，防止误把局部预览覆盖正式整本。依赖 include 仍用完整 catalog 解析成跳板短名。`OutFile` 必须以 `.pdf` 结尾，相对路径从库根解析；目录自动创建，配套 `.typ` 跟随输出位置。

`SoloMin 90` 让达到 90 行的代码/笔记及插件从奇数页起排，可能产生双面打印空页；README 跟随代码，不单独参与阈值。默认 0 不为奇偶补空页。

打印设置：A4 横向、实际大小 / 100%、每张纸 1 页 PDF、双面短边翻转、黑白保留灰度。先试印一页确认代码与注释清晰、页边未裁切，再打印整本。

## 怎样保证是当前版本

本地编辑不会自动刷新旧 PDF，打印前重新运行任务。封面显示生成日期和筛选范围；目录、页码和指纹随本次内容一起更新。可从 GitHub Actions 的 **booklet** 作业下载对应 push/PR 的附件，附件名包含运行编号；失败时不能把旧 PDF 当成本次成功产物。

CI 自动检查目录新增/改名/空目录筛选、说明发现、公式与错误输入，并实际编译整本和 1200 行增长样例；目录清单独立对照文件树，PDF 的目录与书签逐项核对文件夹和源码的名称、顺序及层级。构建还检查每份实现连同说明的页段互不占用，读取 PDF 检查数学字体、增长行序和 MIKU 只出现在第 39 页。CI 不回写或提交生成物。

实现与维护入口见 [手册生成约定](../maintenance/README.md#手册生成约定)。
