# 库里有什么

这份库包含 C++20 算法模板，以及从写题、对拍到展开提交、打印手册的脚本。

## 算法

下面概括当前 catalog 中有跳板的代码；每个实现的具体限制、接口和内存预算看源码类头与 Usage。

| 方向 | 目前能找到的代码 |
|---|---|
| 数据结构 | 普通/动态/可持久化线段树、合并分裂，树状数组与二维树状数组，ST 表，并查集与带权并查集，左偏树与可持久化左偏树，单调队列，AVL/Treap/FHQ/Splay/替罪羊树/跳表/笛卡尔树，线段树套 FHQ |
| 树与图 | 图存储，SCC/边双/点双/圆方树，多种 LCA、树链剖分、虚树，树直径、中心与重心，欧拉路径、拓扑排序、线段树建图，最短路与负环检测 |
| 动态规划 | 两种树上背包实现 |
| 字符串 | Trie 与可持久化 Trie |
| 数学 | 模整数、高精度、区间筛、整数开方、除法上下取整、约数个数/和、Lucas 和多种组合数计算 |
| 常用底座 | 类型别名、调试与常用头，快读快写、128 位整数、随机数、哈希防卡、离散化、Misra–Gries |

**[打开完整算法目录：查名称、跳板和源码](catalog.md)**。目录由 catalog 自动生成，不手工维护第二份清单。

目前 catalog 中的网络流（Dinic/MCMF）、AC 自动机、后缀数组/自动机、FFT、莫比乌斯反演、矩阵树定理、计算几何及多数 DP 条目登记为笔记，没有可直接 include 的跳板。不要把笔记、目录骨架当成已交付引擎。

登记为代码只表示库里有这个实现。想知道测得怎样看 [口语概览](../verification/status.md), 具体 API、边界和运行证据看 [AI 明细](../verification/details.md); [测试资产表](../../rules/reliability.md) 只列模板与套件的静态关联; 待补与待裁决项看 [工作板](../../rules/sweep-board.md)。示例、插件和未维护代码等豁免项不列为现役跳板，仍可从 [源码目录](../../algorithms) 和 catalog 豁免行追溯。

本轮逐项缺口见 [全库审查](../../records/tooling/repo-audit-20260906.md)。

| 对拍现状 | 运行 run_checks.ps1 后自动更新两层表, 无需手填结果; 展示已测内容、缺口和环境 | [口语概览](../verification/status.md) / [使用说明](../verification/README.md) |

| 库维护 | 生成跳板、更新目录和测试资产表、生成队友 ZIP | [维护说明](../maintenance/README.md) |
| AI 工作与交接 | 临时产物放库内, 任务与结论写进规则、工作板和证据记录, 后续接手可追溯 | [工作区与沉淀](../../rules/collab.md#工作区与沉淀) |

对拍内容由维护者编写或升级, 执行脚本会自动找到 `algorithms` 下的 `*_check.cpp`,
在每次 push/PR 的普通回归与 sanitizer 中运行默认用例, 无需逐个添加到 CI。
额外参数模式需要维护者显式接入; 当前 LCA/虚树的百万点、增栈深链与默认栈探针已由独立
压力作业自动运行。Graph、拓扑、树属性、HLD 和连通性四件套也已有 20 万点补验,
递归部分另在 256 MiB 栈下跑深链, 普通与 ASan/UBSan 都自动执行。
这只代表上述范围的补验, 全库剩余模板仍按工作板逐件推进。
脚本不会自动生成暴力或推断漏测范围, 已知栈限制单独报告, 不当作算法通过。

安装包不附带 VS Code、插件、编译器或 Typst；按你实际使用的功能准备对应工具。
队友包包含测试源码及其 CI 配置依赖, 在具备对应工具的环境中可以运行验证入口。

对拍表由登记范围与真实运行记录生成, 没登记的范围仍显示未知。代码改动后需运行生成器才能刷新;
CI 结果随附件提供, 不自动回写仓库。维护与导入操作见 [验证指南](../verification/README.md)。

本项目的临时工作文件和编译中间产物放在库内忽略目录, 长期结论存入受版本控制的正文与记录;
不靠保留 C 盘会话副本交接。该约定不迁移应用自身缓存或 WSL 系统盘。

学习与整理进度另见 [学习与入库进度表](../progress/README.md)，有代码不等于本人学过。
