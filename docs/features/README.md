带权并查集支持普通距离与取模关系, 已连通后的新约束会被忽略, 不负责判矛盾;
判断连通请用 same, 不能只比较 query 是否等于 INF。两份并查集均迭代查根并保持合并方向,
WDSU 可用 init 在原容量内清空并切换距离模式; 默认对拍包含 20 万点退化与多测, 见 [源码契约与 Usage](../../algorithms/数据结构/并查集/WDSU.cpp)。

单调队列与单调栈保留可直接按题改的 while 骨架: 滑窗最值、有限前驱 DP、左侧最近大小关系,
并解释平手取舍和左右边界。`mono_window/mono_stack` 返回 1-based 下标数组, 无答案为 0;
旧 MonotonicQueue 类及 get_min/get_max 已撤下。两件的 20 万规模用例自动进入 CI,
见 [队列用法](../../algorithms/数据结构/单调队列/单调队列.cpp) 和 [单调栈用法](../../algorithms/数据结构/单调栈/单调栈.cpp)。

普通/动态线段树支持按 Info/Tag 定制修改、查询与找位置; 动态版 clear/init 及自动清空的 build 可复用内存池, 查询下传也会开点。两版找位置都要求区间存在性判据, 不自动累加前缀; ST 表提供静态最大/最小值。[源码契约与 Usage](../../algorithms/数据结构/线段树/泛型动态线段树.cpp)

线段树提供七组可直接组装的 Info/Tag：加法最值、赋值加法、仿射平方和、异或计数、01 连续段、最大子段和、等差加法。各组有独立命名空间与完整 Usage；Binary/Linear 须先 build，其他五组支持动态树全零虚区间。真实插件的双引擎与每组 20 万规模测试自动进入普通及 sanitizer CI。[插件选型](../../algorithms/数据结构/线段树/泛型插件/README.md)

有序表区分跳表去重和五种树的重复元素, 序列 FHQ 支持区间变换, 笛卡尔树提供双堆型及顺序插入 BST 拓扑。八件的 20 万规模对拍已纳入默认 CI; Splay 无解查询也伸展, 序列最大子段和仍须遵守加乘限制。[序列 FHQ 契约与 Usage](../../algorithms/数据结构/有序表与平衡树/FHQ_Treap_序列.cpp)

主席树支持历史根分叉、加法区间和/最值、左右找位置和多根计数第 k 小; 查询不开新结点。默认 CI 覆盖 20 万前缀版本及范围分支, 根与值域生命周期见 [主席树契约与 Usage](../../algorithms/数据结构/线段树/可持久化线段树/主席树.cpp)。

树状数组提供一维区间加/和及后缀版, 二维支持稠密矩形加/和; init 在构造容量内清空复用。
默认 CI 覆盖 20 万长度及 2000×2000 矩阵, 坐标乘积等中间值也须不溢出。[源码契约与 Usage](../../algorithms/数据结构/树状数组/树状数组.cpp)

普通左偏树支持逻辑编号的合并、删点与堆级修改, 查根改为迭代路径压缩; 可持久化版支持共享历史堆合并。
默认 CI 覆盖 20 万点/版本; 懒标记与原地 merge_raw 各有使用限制。[源码契约与 Usage](../../algorithms/数据结构/堆/左偏树/左偏树.cpp)

[模整数 mint](../../algorithms/数学/数论/mint.cpp) 支持固定模数的双向混合四则与比较、完整 i128 指数和任意位数十进制输入。
保留 `init_fact/comb`：素数模预处理后 O(1) 查询且 n<MOD；合数模逐因子相消，适合少量查询。
除法和负指数要求可逆。原 mint_check 已加入 15 种模数边界、20 万运算/位数/表重建，默认自动进入 CI；范围见 [专项验证](../../records/verification/mint-20260907.md)。

组合数另保留四种运行时模数方案，完整用法在源码 Usage：
[循环法](../../algorithms/数学/组合数学/循环求组合数.cpp) 用于大 n、小 k，无需建到 n；
[PrimeComb](../../algorithms/数学/组合数学/阶乘表及阶乘逆元表求组合数.cpp) 为素数阶乘表，固定模数时可用 mint 代替；
[PascalComb](../../algorithms/数学/组合数学/打表杨辉三角求组合数.cpp) 用 O(n²) 预处理支持合数模下 O(1) 查询；
[Lucas](../../algorithms/数学/组合数学/卢卡斯定理求组合数.cpp) 复用 PrimeComb，处理大 n/k 与可建表的小素数 p。
PrimeComb 要求 n<p，循环法要求 min(k,n-k)<p，Lucas 不能处理任意合数模；素数由调用方保证。
旧全局 get_C/init_C/init_fact/init_lucas 调用改为 Usage 中的 binom_loop 或对象 init/comb，避免多份同时引用时重名。
默认对拍覆盖 500 万阶乘、2000 杨辉表及 20 万 Lucas 查询，见 [组合数学验收](../../records/verification/combinatorics-20260908.md)。

[BigInt](../../algorithms/数学/高精度计算/高精度.cpp) 与 [快读快写 rw](../../algorithms/杂项/快读快写/快读快写.cpp) 是直接调用的工具内核，源码尾部都有可运行 Usage。
BigInt 支持有符号大整数四则、商余、开方、幂、gcd/lcm 和阶乘；商向零取整，`mod` 返回非负余数，转原生整数须在目标范围内。
rw 自包含，支持原生整数及 i128/u128、浮点和文本；浮点固定输出六位小数，正常退出自动刷写，同一标准流不要混用其他 IO。
独立 Python 对拍覆盖十万位与 `100000!`，快读写覆盖百万整数、缓冲区边界和退出刷写；深测与 Usage 自动进入 CI，见 [运行方式](../../scripts/checks.md#bigint-与-rw-深度验证)。

[防卡哈希](../../algorithms/杂项/防卡/哈希防卡.cpp) 使用 SipHash-4-8 与每对象随机密钥，支持 64 位以内整数、字符串原始字节和整数对；原 `custom_hash` 类型名保留。
这是一份防卡优先的实现，计算比旧 SplitMix64 慢；密钥来自 `random_device`，依赖其实现提供的熵，不把桶分布测试当密码安全证明，也不承诺最坏 O(1)。需要确定性复杂度时用 map/set 或排序。
配合 `max_load_factor` 和 `reserve` 的完整写法见源码 Usage；以作者参考实现核验、构造性同桶输入和容器复用验证见 [杂项验收](../../records/verification/misc-20260908.md)。

其他杂项均有可运行 Usage：[独立 i128 流读写](../../algorithms/杂项/128位整数/128int.cpp) 覆盖完整有符号范围；
[随机数](../../algorithms/杂项/随机数/z_rnd.cpp) 支持 bool/字符和有限浮点区间，可显式传引擎复现，但不用于生成安全密钥；
[离散化](../../algorithms/杂项/离散化/离散化.cpp) 提供 clear、多测复用和 1-based 排名，输入 vector 不自动忽略首项；
[Misra–Gries](../../algorithms/杂项/主元素问题/Misra-Gries.cpp) 返回真实频次严格超过 n/k 的值，需要二次计数，适合小 k；
[utils](../../algorithms/杂项/utils/utils.cpp) 的 z_fill_n 从下标 0 起填至多 n+10 项，保持旧余量语义，不清空更远尾部。

登记为代码只表示库里有这个实现。想知道测得怎样看 [口语概览](../verification/status.md), 具体 API、边界和运行证据看 [AI 明细](../verification/details.md); [测试资产表](../../rules/reliability.md) 只列模板与套件的静态关联; 待补与待裁决项看 [工作板](../../rules/sweep-board.md)。示例、插件和未维护代码等豁免项不列为现役跳板，仍可从 [源码目录](../../algorithms) 和 catalog 豁免行追溯。

本轮逐项缺口见 [全库审查](../../records/tooling/repo-audit-20260906.md)。

[普通 Trie](../../algorithms/字符串/字典树/字典树.cpp) 支持单词次数、前缀次数与非负整数最大异或；
[可持久化 Trie](../../algorithms/字符串/字典树/可持久化字典树.cpp) 可从任意历史版本分叉，查询区间/树路径的根差、前缀计数、与某个单词的最长 LCP，以及多行多列异或值的第 k 大（重复计数）。
字符串与整数分别建对象；根差必须保证每个值的剩余次数非负。字符串插入不再随串长递归，多根中间计数使用 LL。
普通版容量包含根，持久化容量不含空哨兵，每次新增串长+1或HB+2个结点；具体预算、空集合返回值和完整程序见两份源码 Usage。

数论筛法现有三种：[欧拉筛](../../algorithms/数学/数论/质数筛/欧拉筛.cpp) 以 O(n) 建最小质因子表，支持表内整数快速分解；
[埃氏筛](../../algorithms/数学/数论/质数筛/埃氏筛.cpp) 用位压缩标记，只需质数表时更省空间；
[区间筛](../../algorithms/数学/数论/质数筛/区间筛质数.cpp) 复用埃氏筛，筛指定闭区间，但基础表仍须建到 sqrt(r)。两种全域筛都用 init 全量重建，不能当作增量续筛。
[约数统计](../../algorithms/数学/数论/约数/约数个数及约数和公式法.cpp) 改为 `auto [cnt, sum] = deprime(x)`，返回正 int 的约数个数与和，不再写全局变量。
整数开方保留整数校正；除法上下取整支持正负号，零分母及 LLONG_MIN/-1 不在契约内。两件已并入 utils，其余四件仍为独立固定引擎，完整 Usage 在源码尾部。
莫比乌斯/数论分块仍保留为启发式笔记或待建知识点；本轮只补反演方向与贡献推导，未把它们登记成可调用模板。

对拍内容由维护者编写或升级, 执行脚本会自动找到 `algorithms` 下的 `*_check.cpp`,
在每次 push/PR 的普通回归与 sanitizer 中运行默认用例, 无需逐个添加到 CI。
额外参数模式需要维护者显式接入; 当前 LCA/虚树的百万点、增栈深链与默认栈探针已由独立
压力作业自动运行。Graph、拓扑、树属性、HLD 和连通性四件套也已有 20 万点补验,
递归部分另在 256 MiB 栈下跑深链, 普通与 ASan/UBSan 都自动执行。
这只代表上述范围的补验, 全库剩余模板仍按工作板逐件推进。
脚本不会自动生成暴力或推断漏测范围, 已知栈限制单独报告, 不当作算法通过。
图论专项压力的自检同时覆盖两种 profile 的启动与报告流程；依赖指纹只追踪实际 include，跳过 Usage 注释和 raw string 示例，真实依赖缺失仍会报错。
线段树优化建图现可单独设置新增中继点容量, 适用于原点少、操作多的情况;
默认对拍已覆盖 20 万规模及 Dijkstra/SCC 组合, 用法见 [优化建图契约与 Usage](../../algorithms/图论/优化建图/线段树优化建图.cpp)。

[树上倍增优化建图](../../algorithms/图论/优化建图/树上倍增优化建图.cpp) 提供 `treeGraph.h`：在静态森林上连接点与路径、路径与路径，每条路径至多用四个可重叠倍增段表示，路径间至多新增八条边和一个中继点。定位仍需倍增跳转，配主力 LCA 时每次为 O(log n)，总边数为 O(n log n + q)。原树只定义路径，可通行树边由调用方显式加入；两条路径可以位于不同树，任一路径自身断连则忽略操作。支持 int、LL 和 Empty，中继容量独立设置；默认对拍包含百万操作与 20 万点森林，不为原有 LCA 的递归深链承诺额外栈容量。

单源最短路提供堆版/朴素 Dijkstra、SPFA 和 Bellman-Ford，每次运行前 init；前两者用于非负权，后两者允许负边但可达部分不能有负环。全图判负环另有 BF/SPFA 两版，工作距离统一引用库内 i128，run 自带清空。普通 SPFA 在稀疏图也可能退化，不能因 20 万点特定样例通过就当作通用大图首选。六份的独立 Floyd、边界与规模测试已接入默认 CI；接口与 Usage 从 [算法目录](catalog.md#图论) 查阅。

最小生成树提供 [Kruskal](../../algorithms/图论/生成树问题/最小生成树/kruskal/Kruskal.cpp) 和 [朴素 Prim](../../algorithms/图论/生成树问题/最小生成树/prim/Prim.cpp)，分别适合稀疏与稠密图。两者接无向 Graph，build(g,n) 返回是否连通，同时给出总权、分量数和选中边；断连时保留最小生成森林。支持负权、重边和自环，总权累加须在 LL 内。默认 CI 运行独立枚举暴力、20 万点 Kruskal 与 2000 点稠密图验证。
