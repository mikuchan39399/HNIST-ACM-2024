## 离线算法

| 条目 | 当前身份 | 设计类型 |
| --- | --- | --- |
| 离线算法 / 线段树分治（目录） | 待建知识点 | 固定内核加题目骨架 |
| [离线算法 / 整体二分 / 整体二分_回滚.cpp](<../../../algorithms/杂项/离线算法/整体二分/整体二分_回滚.cpp>) | 现役 pbsRollback.h，静态第 k 小完整骨架 | 固定内核加题目骨架 |
| [离线算法 / 整体二分 / 整体二分_指针.cpp](<../../../algorithms/杂项/离线算法/整体二分/整体二分_指针.cpp>) | 现役 pbsPointer.h，静态第 k 小完整骨架 | 固定内核加题目骨架 |
| 离线算法 / CDQ分治（目录） | 待建知识点 | 固定内核加题目骨架 |

整体二分固定的是值域递归与稳定分流，题目决定事件、贡献、判定及排名语义；因此归第三类，而不是纯启发式骨架。两份分别提供 `PBSRollback::range_kth` 与 `PBSPointer::range_kth`，公开同形 `Event` 并保留独立源码，调用方完成离散化、统一编排事件后传入 `range_kth(n, q, d)`，方便对照改题；跳板只负责引入，不要求把所有整体二分问题装进同一个接口。

静态区间第 k 小可直接调用；其他题展开后改骨架。回滚版每层维护当前左半值域并扣减右侧排名；指针版维护全局 `val <= mid` 且保留原排名，不能混用两种状态。当前均未实现带修改版本。
