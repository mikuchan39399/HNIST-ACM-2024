## 离线算法

| 条目 | 当前身份 | 设计类型 |
| --- | --- | --- |
| 离线算法 / 线段树分治（目录） | 待建知识点 | 固定内核加题目骨架 |
| [离线算法 / 整体二分 / 整体二分_回滚.cpp](<../../../algorithms/杂项/离线算法/整体二分/整体二分_回滚.cpp>) | 现役 pbsRollback.h，静态第 k 小完整骨架 | 固定内核加题目骨架 |
| [离线算法 / 整体二分 / 整体二分_指针.cpp](<../../../algorithms/杂项/离线算法/整体二分/整体二分_指针.cpp>) | 现役 pbsPointer.h，静态第 k 小完整骨架 | 固定内核加题目骨架 |
| 离线算法 / CDQ分治（目录） | 待建知识点 | 固定内核加题目骨架 |

整体二分固定的是值域递归、稳定分流与两种排名语义，坐标及贡献统计由题目决定，仍归固定内核加题目骨架。两份各自保留默认 `Event`；模板参数 `E = Event` 可缺省，也可从调用方的 `vector<E>` 自动推导。`find_first(n, V, q, add, query)` 固定读取 `type/val/k/id` 四个整数字段，自定义事件时不能改名或省略；`pos/l/r` 或矩阵坐标仅由回调读取，可随题改名、替换或删除，并同步修改回调和初始化。其他字段可用整数、pair 或附加元数据。两个 lambda 直接连接具体统计结构，不引入继承、虚函数或通用策略对象。

一维与二维均调用 `find_first`，外部提供 `BIT` 或 `BIT2D` 及统计回调，返回离散排名后用 `d[ans[id]]` 还原。内核只依赖 utils，BIT 与离散化由调用方显式引入。事件表按值接收，可 `move(q)`；外部统计初始为空，正常返回时也为空，指针版最终撤销剩余前缀，便于连续调用。

内核显露扫描事件、稳定划分与递归，方便回忆和按题修改；回滚版逐层撤销并扣减 k，指针版保留原 k 并移动全局前缀。只支持先插入后询问的静态第 k 小，带修改或不同分流语义仍需改骨架；不为这些未实现的场景增加回调。

唯一调用接口为 `find_first`，表示找累计计数首次达到目标的最小答案坐标。通用名称不扩展当前静态单位计数的契约；加权贡献、无解与数值范围仍须按题适配。
