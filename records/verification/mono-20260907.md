# P11 单调队列与追加单调栈

2026-09-07, 用户批准将单调队列改为显式 while 的启发式骨架, 并追加单调栈。先增强旧队列对拍, 再验证新实现, 最后润色注释与 Usage。当前改动尚未提交推送, 不以此前在线 CI 的结果代替本轮结果。

## 交付与取舍

- 单调队列撤下旧 MonotonicQueue 类、空操作 init 和重复的 get_min/get_max 循环。mono_window 返回按完整窗口右端点索引的最值下标, 默认最小且平手取最右; 谓词可改为最大或同值取最左。旧最值列表的迁移说明已写入 README。
- mono_dp 示范 f[0]=0、从前 k 个状态取 min 后加 cost[i] 的递推。保留先过期、再转移、最后插入新状态的顺序; 它不是任意 DP 的通用求解器。
- 新 monoStack.h 登记到 catalog。mono_stack 默认返回左侧最近严格较小元素下标, 可改为 <= / > / >=; 循环保留弹栈、读取答案、入栈。README 解释反向扫描、反转映射、弹出点的右侧答案和区间贡献的相等值归属。
- 两件只引用 utils, 不重复普通标准头或命名空间。输入 1-based 且含 0 号哨兵, 无答案返回 0; 局部数组各次调用独立。数组存全扫描候选, 不增加环形队列或通用容器封装。

## 默认测试范围

沿用 algorithms/杂项/对拍/misc_check.cpp, 原离散化、哈希和快读写测试保留。

| 范围 | 独立参照与边界 |
|---|---|
| 滑窗 | 种子 42, 400 组逐窗口全扫描, 四种比较逐下标核对; 300 组自定义载荷, 全同值左右平手、int/LL 极值、空态和 k>n |
| 大滑窗 | 20 万-1-257-20 万长度; 正序、倒序、全同、LL 极值交替、锯齿、随机, 六种窗口宽度; 分块前后缀最值独立参照, 同时核对输入不变 |
| DP | 600 组 O(nk) 暴力, 合法 LL 极值; 20 万及大小多测, 正/零/负常费用闭式答案; 两种大随机窗口以 multiset 保留全部合法前驱, 不做支配淘汰 |
| 单调栈 | 600 组逐点向左扫描, 四种严格/非严格关系, 反转求右侧示例直接向右扫描; 300 组自定义载荷及 int 极值 |
| 大单调栈 | 20 万-0-1-257-20 万长度, 同上六形态; 四种关系用离散化加 Fenwick 前缀最大下标逐项核对, 不复用单调栈机制; 输入不变 |

范围登记为两条 misc 覆盖关系, 所有规模用例位于默认 main。现有 check_inventory 自动发现 misc_check, push/PR 的普通与 sanitizer CI 会自动执行本轮新增内容, 没有需要手工启动的验收参数, 无需修改 workflow。

## 适用限制

比较须为固定一致的大小顺序, 存活候选的关键字不可变; DP 加法在 LL 内。大滑窗主要核对最值, 四种同值下标策略由小暴力覆盖。README 中的区间贡献与弹出点赋值是按题改法提示, 不宣称已交付通用贡献引擎。后续改变循环或转移式需重新按题验证。
