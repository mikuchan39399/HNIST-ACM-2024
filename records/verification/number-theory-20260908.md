# 数论两筛与现役四件验收

日期：2026-09-08。按用户要求新增欧拉筛和埃氏筛，整理区间筛、整数开方、约数统计、除法取整及莫比乌斯笔记。已验收的 mint 保持不变；未提交或推送，保留此前其他改动。

## 设计与接口

六个数值工具都按现有分类采用固定引擎。莫比乌斯反演与数论分块按启发式处理，目前仍是笔记或待建目录，不把本轮公式整理说成建成了新引擎。

| 实现 | 本轮结果 |
|---|---|
| [欧拉筛](../../algorithms/数学/数论/欧拉筛.cpp) | 新增 `eulerSieve.h` / `LinearSieve`，O(n) 保存最小质因子 lp 与升序 primes，提供 is_prime/factorize |
| [埃氏筛](../../algorithms/数学/数论/埃氏筛.cpp) | 新增 `eratosthenes.h` / `Eratosthenes`，vector<bool> 位压缩标记与升序 primes，O(n log log n)，不保存最小质因子 |
| [区间筛](../../algorithms/数学/数论/区间筛质数.cpp) | 复用真实 Eratosthenes，基础与区间标记均位压缩；保留安全定位首倍数和避免末次递增溢出的循环 |
| [整数开方](../../algorithms/数学/数论/整数开方.cpp) | 保留浮点估计后整数除法校正，补 inline 与完整 Usage，不引入无必要的新算法 |
| [约数统计](../../algorithms/数学/数论/约数个数及约数和公式法.cpp) | 跳过2以外的偶因子，返回 pair<int,LL>；移除全局 cnt/sum，结果可跨调用保存 |
| [除法取整](../../algorithms/数学/数论/除法上下取整.cpp) | 补守卫、统一 utils 依赖、完整 Usage；说明并断言零分母与 LLONG_MIN/-1 不在合法域 |

约数统计的调用迁移为 `auto [cnt, sum] = deprime(x)`，仍只接正 int。库内搜索到的实际调用方只有对应对拍，已同步迁移。原全局变量模式容易冲突或被后续调用覆盖，本轮没有把无效负数/零输入伪装成正确答案。

筛的 init 都是覆盖式重建，不是增量续筛；缩表保留容量。n=1e7 时，欧拉筛的有效数组数据约42.7MB，埃氏筛约3.9MB；这些数不含 vector 超额容量、分配器、其他对象和测试进程开销，也不是速度排名。输入上界为可分配的 0<=n<INT_MAX，查询必须在已建范围内，factorize 接1..n。

区间筛仍须处理 sqrt(r) 基础表，要求 sqrt(r)<INT_MAX 且基础/区间表都能容纳；不能凭“区间很短”就拿它处理 LLONG_MAX 附近。整数开方对非正数返回0；除法返回 LL，因此排除数学商无法放入 LL 的 LLONG_MIN/-1，不做溢出哨兵约定。

[莫比乌斯笔记](../../algorithms/数学/数论/莫比乌斯反演.txt) 补了消去式、约数/倍数两个反演方向、互质数对推导、由最小质因子递推 mu、两个商同时不变的分块右端点以及 i128 中间贡献。仍明确换题时要重推系数和贡献，尚未登记为可调用模板。没有新增算法 README。

## 默认深度验证

[number_sieve_check.cpp](../../algorithms/数学/数论/对拍/number_sieve_check.cpp)：

- 两筛300轮随机0..1000表，小表每个数独立试除核对；欧拉筛分解与试除所得完整质因子列表比对。
- 两筛执行1000万—0—1—2—257—100万—1000万重建，逐点核对判素标记与质数列表顺序，另一个对象全程保持原结果。
- 大表参照使用 Sundaram 奇合数枚举，来自 `(2i+1)(2j+1)=2(i+j+2ij)+1`；小表先用试除核实此参照。没有只用新欧拉筛和新埃氏筛互拍。
- 对所有 lp 检查质因子合法、整除与沿商链非降，以唯一分解核实最小质因子；每轮至多2万个分解结果检查质因子严格递增、指数正和乘回原数。
- 区间筛完整比对[0,100万]及后半区间，参照独立Sundaram；p=2/3/5/97/997/999983的平方前后各128点与平方单点由逐数试除核实，最大坐标接近1e12。另有300个1e10内随机短区间，含空区间和极端负端点的提前返回。

[number_boundary_check.cpp](../../algorithms/数学/数论/对拍/number_boundary_check.cpp)：

- 保留1000轮随机平方根、短区间筛与约数统计及既有确定性边界。
- 平方根新增10万个随机非负LL、10万个随机根的平方前/自身/后，共40万次 check_sqrt，另核查LLONG_MAX往下10001个值；每次同时核实 floor/ceil，参照纯整数二分与i128平方。
- 约数统计对1..20万每个输入与“枚举约数的倍数并累加”的独立答案比对；300个大int含INT_MAX往下100个值用因子对枚举。覆盖1、素数、质数幂、大合数和多调用结果隔离。
- 取整除法检查小整数全符号笛卡尔积、LL边界交叉与20万对完整64位随机输入；独立参照提升i128、归正分母后按绝对值计算，不复制实现的余数符号分支。无效除法不作为合法用例。
- 重复include检验守卫；六份源码在额外两个翻译单元共同编译链接，确认头文件组合不因全局定义重名而失败。

两套无参数 main 自动被既有普通/sanitizer CI 发现，没有新增必须手工执行的验收模式。莫比乌斯笔记未混入可运行通过列表。
