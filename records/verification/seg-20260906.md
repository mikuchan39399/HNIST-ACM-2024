## 已运行内容

- 原随机用例保留。新增 mt19937(42), 400 组仿射标记逐点暴力, 含赋值、加法、取负及非交换叠加,
  同时核对 len/sum/min/max、find_first/last 和明确返回 -1 的越界起终点。
- 400 组整段等差标记与任意子区间查询, 覆盖 split_tag; 400 组区间 chmin 逐点暴力,
  覆盖 break_cond/tag_cond/get_real_tag。它们是独立测试代数, 不等于现有插件文件已经验收。
- 静态/动态各 20 万长度、20 万次区间修改及查询, 用独立差分 Fenwick 积分核对区间和与长度;
  动态池 build 恰好使用 2n-1 个结点。此大规模通道不单独声称核对每次最大值。
- 静态版大-小-非二次幂-大重建及大负偏移二分, 每个规模 25000 次找位置。
- 动态版 1e12 值域上 20 万次间隔 4096 的插点, 每步以等差坐标计数公式核对任意区间
  len/sum/max、左右查找。实际 2799978 个结点, 40 B/结点, 已用约 112 MB, 构造预留约 160 MB。
- 动态版空虚树、全区间懒标记后访问虚子树、负值、LLONG_MAX 坐标边界、哨兵不被污染;
  巨大区间的非零权和仍要求调用方确保 LL 不溢出。
- ST 400 组全部子区间 max/min 暴力, LL 两端、全同值、同实例模式切换;
  20 万-1-2-65537-20 万重建, 每规模每模式 10 万次闭式答案查询。

## 接口裁决与最终验收

旧 DySegTree 没有 clear/init, build 每次重新分配整棵树并保留旧池结点。
用户确认增加 clear() 保留值域/容量、init(n) 清空并改值域、build 自带清空。
已实现并补大-小-大重建、完全用满 2n-1 预算后重建、单结点预算 100 次重复 build、
清空后虚区间查询和 1e12 值域切换测试, 保留容量并恢复哨兵。Windows p05-reset 与 Linux 普通/sanitizer
通过后才整理注释, 保持原构造与查询签名。

三份模板的普通标准头和命名空间统一到 utils; 动态版补接口与内存说明, 静态版 Usage 改用 mx
作为存在性判据, ST 校正内存估算并说明静态与重复覆盖性质。三份 Usage 均提取、重复 include、
C++20 -Wall -Wextra -Werror 编译运行, 输出分别为 `11 / 3 3`、`9 / 2 4 / 5`、`7 -2 / -9`。

最终 Windows GCC 15.2 全部 23 套回归通过, 日志 .ci-results/p05-final, runner 自动保存证据与两层表。
