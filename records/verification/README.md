# 自动验证证据

runs 中的 JSON 由 run_checks.ps1 自动写入, 每轮独立记录, 不手工伪造或改写通过状态. 它保存源码指纹与运行结果, 不包含原始日志内容.

两层表和导入 CI 证据的方法见 [对拍现状指南](../../docs/verification/README.md). 生成表时同套件、操作系统、检查方式取最新记录, 老记录保留供追溯.
