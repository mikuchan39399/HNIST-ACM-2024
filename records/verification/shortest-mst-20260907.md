# 单源最短路、负环与最小生成树（2026-09-07）

用户指定整理单源最短路四份、负环两份，并补齐 Kruskal/Prim；八项均明确确认“学过待复习”。不新增模板 README，原先仅用户选定的四份说明继续入册。当前状态从 [验证概览](../../docs/verification/status.md) 查阅。

## 范围与决定

- 保留四份单源最短路的构造/init/run 接口，明确每次运行前 init、不可达 INF 与候选运算范围。Dijkstra 堆版对重复源去重，修正堆含过期项时按 O(n+m) 而非 O(n) 估算空间的注释。
- 两份判环的 12 点/-10^18 自环在旧版中均被 UBSan 报告 LL 下溢，退出码 1。用户同意扩大工作距离，并要求复用库内底座；现直接引用 `128int.cpp` 的 i128，Graph 边权仍为 int/LL，bool 接口不变。每点多 8 B，20 万点约多 1.6 MB；没有另造整数或图容器。
- 普通 SPFA/BF 只要求源点可达部分无负环，全图判环则覆盖所有分量。判环 run 每次自动清空，dist 仅为工作量，不解释为负环图上的最短距离。
- Kruskal、Prim 原先均为目录骨架，本轮建成。两者 `build(g,n)` 接成对半边的无向 Graph，自带复位并返回是否连通；weight/components/edges 始终保留最小生成森林，总权累加须在 LL 内，选边为偶数半边编号。Kruskal 使用已有 DSU，调用前按集合大小选合并方向；Prim 为适合稠密图的朴素 O(n²+m) 版。
- 先写并运行独立对拍与规模验证，再整理注释和完整 Usage；最终注释变化也重跑相关入口。没有借本轮整理修改 Graph、DSU 或 i128 底座实现。

旧最短路段只有三组各 200 图，主要依赖四版距离和两版判环互拍。本轮直接升级原段，未保留两套竞争的最短路套件。MST 是新职责，单独新增 mst_check。

SPFA 的性能限制是真实保留项：首次加入 20 万点“先跨点、后邻点”的非负稀疏图后，graph_check 在 120 秒限制下超时，记录 [失败基线](runs/b4febbd626f94caab5c484b1ee67302f.json)。同形态缩至 1800 点后，真实模板扫描 1,619,100 次边，默认套件保留此用例和计数断言。20 万点容量测试采用能合理收敛的链/邻接顺序；未加入 SLF 等不能改变最坏界的启发式，也未把超时抹成正确性故障。
