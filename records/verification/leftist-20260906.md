# P09 左偏树双件验证 (2026-09-06)

范围为 LeftistTree、PersistentLeftist 与原 leftist_check。保留此前 P05-P08 改动, 本轮未提交推送。

## 真实缺陷与授权

普通版递减值 -1..-200000, 依次 merge(i-1,i), 最后 get_top_id(1),
形成 20 万层所属堆父链。旧递归 find_root 在 Windows GCC 15.2/O2 下退出 -1073741571
(0xC00000FD, 栈溢出); 探针在 .zoi-checks/codex-work/p09/deep.cpp。
同一探针 Linux GCC 13.1/O1/ASan+UBSan/8 MiB 栈退出 0, 不将此描述为 Linux 失败。

用户明确批准仅 find_root 改为迭代路径压缩, 左偏树 merge_trees 保留递归。
修复不改变外部接口, 该 20 万层反例已写入默认套件, 在 Windows 及 Linux 自动回归。
迭代消除查根递归栈消耗, 不改变首次线性父链扫描的时间。

## 先验证再注释

- 保留普通版单点域、懒标记域各 300 组朴素成员表, 原持久化 multiset 快照从 200 增至 300 组。
- 普通大小根堆各做 20 万-1-20 万重建, 大轮每次 10 万 set_val/add_val/add_all 混合操作,
  独立 set 按值与编号排序, 独立总和/全局偏移核对堆顶、单点值、大小和总和。
  批量惰删偶数点, 再按 set 弹空, 覆盖大量旧物理点清理。
- 20 万递减值顺序合并, 查询最早点, 再进行 10 万 heap_add/add_all 与两次正倍乘,
  按仿射公式核对后完整弹空; 大小空与默认零初值复位。
- 持久化大小根堆各三形态, 单调递增/递减与全同值, 各 20 万前缀插入版本再完整弹空,
  回访历史版本 size/sum, 不同键核对 top_pay。最多使用 6987157 结点, LL+int 共 36 B/点,
  已用约 251.5 MB; 测试预留 800 万点约 288 MB, 不套用脱离题目的 128 MB 限制。
- 另 300 组任意历史分叉, 每次逐字段比较所有旧结点 lc/rc/dist/sz/pay/val/hsum,
  multiset 快照独立核对历史根; 查询不分配。包括共享/自身合并。
- 最终补充 300 次小容量复位、载荷结构体、大数正负抵消、同值小编号、死点返回值,
  单点池重建和 30 次自合并表示 2^30 个逻辑元素。
  merge_raw 只验证独占两堆建堆, 之后再函数式共享; 不对违反独占契约的输入做伪反例。

修复后、注释前 Windows 增强基线 PASS, 约 7.04 秒, 日志 .ci-results/p09-baseline。
Linux 普通约 3.30 秒、ASan/UBSan 约 13.69 秒, 8 MiB 栈均 PASS 且 stable=true,

## 说明与边界

统一普通标准头和命名空间到 utils, 删除多余 public 标签, 不调整容量接口。
纠正普通版没有按秩合并却声明 α(N) 的注释, 用实际父链长度 h 和本次清死点数 d 表达成本。
明确堆级懒标记后不能使用非根单点接口, 数值/偏移/标记复合与求和中间值均不得溢出。
普通版 RV 扩展保持注释, 未验收它的全局统计功能。

可持久化版 init 使旧根失效; merge_raw 会改写两个输入, 仅限独占且互不重叠的堆。
函数式 merge 则支持共享/自身合并并重复计数, 逻辑大小不得溢出 int, 同值载荷无稳定顺序保证。
取消固定“每次 40 点”能覆盖所有规模的暗示, 改为按累计路径复制预算。

两份完整 Usage 各重复 include 两次, C++20/Wall/Wextra/Werror 编译运行;
普通输出 2 / 1 / 0 2 / 4 9 / 0, 持久化输出 5 2 5 / 20 / 3 12 / 7, 符合注释。
堆父目录“暂无入库文件”过期说明已修正, 新增双件 README。
学习进度两条原为待确认, 本轮无新的学习陈述, 保持原值。
