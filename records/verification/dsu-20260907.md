# P10 DSU / WDSU：最终验证与整理

此前成果已推送 cae5292，五个在线 CI 作业通过，见 [发布记录](../tooling/release-20260907.md)。本页属于推送后的新范围，已完成本地最终验证与注释整理，尚未提交推送，不沿用此前在线 CI 作为本轮结果。

## 已完成

- 原 DSU 小染色暴力保留；WDSU 原平移暴力由每模式 200 组提高到 300 组，另加 mod=0/1/2/3/5/1000000007 各 350 组独立约束图 BFS，覆盖根合并方向、矛盾声明忽略、正反向距离、孤立点和自合并。
- DSU 增加 20 万-0-1-37-20 万复位、链/星/平衡合并、全点 size/root 及重复合并、257 点分块森林。
- WDSU 增加四模式×链/星/平衡/分块森林各 20 万点及查询，以独立预设势能差为参照；增加 INF 与合法距离碰撞、LLONG_MAX 模数等确定性边界。
- 原 norm(v) 的 `(v % mod + mod) % mod` 对正余数多加一次 mod。mod=LLONG_MAX、merge(1,2,1) 后反向查询即出错；Linux GCC 13 UBSan 报 `9223372036854775807 + 9223372036854775806` 有符号溢出。已最小修复为取余后仅负数补模数，无更宽整数依赖；其他距离运算仍要求中间值在 LL 内。
- 局部修复后的全部小规模/数值用例在 Windows GCC 15.2 普通、Linux GCC 13 普通及 ASan/UBSan 8 MiB 栈通过。
- 完整增强套件在 Windows 显式链接 256 MiB 栈，以及 Linux 256 MiB 栈普通/ASan+UBSan 下通过。增栈结果不能代表默认栈验收。

## 用户裁决与落实

1. 两份模板都固定把第二个根挂到第一个根。连续执行 `merge(i, i-1)`（WDSU 的 w=1）共 20 万点，再查点 1，会形成未压缩长链。Windows 两者均返回 `-1073741571`（0xC00000FD，栈溢出）。用户已批准只把两份 find 改为迭代路径压缩；现用两遍迭代，保持合并方向，额外空间 O(1)，没有改成按大小合并。
2. 用户已批准新增 WDSU::init(n, mod=0)，在构造容量内复位。父亲与距离数组不扩容，模数可切换，省略模数会切回普通距离模式。新增 20 万-0-1-17-20 万×四模式复位，逐项核对原地址/容量不变和全部关系；另加 300 次小多测与默认零容量复位。

先完成迭代实现、复位接口和独立测试，在 Windows 默认链接栈及 Linux 8 MiB 普通/ASan+UBSan 下跑增强基线通过，才整理注释。普通标准头和命名空间统一交给 utils；WDSU::INF 保持兼容并引用公共常量。补两份可运行 Usage 和 README，明确距离方向、矛盾约束忽略、哨兵碰撞、构造容量、复位模式和单次线性复杂度。
