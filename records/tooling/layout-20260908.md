## 路径依赖处理

按十二个子系统梳理：四项原本递归发现，六项有重复路径维护，两项保留人工配置。现行操作和逐项边界在[目录同步指南](../../docs/maintenance/layout.md)，这里仅记录本次实现与验证。

新增纯 PowerShell 同步器，使用源码首行稳定短名定位引擎；自动更新 catalog、跳板、可确定的相对 include、已有 Markdown 链接与验证登记路径。笔记和已登记 suite 按唯一文件名迁移；新引擎短名自动登记。常用展开、对拍、手册、跳板与打包入口以及各 CI 作业先调用同步器，原有只读检查保持只读。

重复短名、同名 suite、目标替换和 include 歧义在写入前拒绝。跳过注释、raw string 与文档代码示例，不重写原始运行 JSON 或冻结原文；实现所能确定的移动之外不猜路径。未登记文件自身移动、被移动的 README 内部相对链接、宏 include、外部题解的中文路径等仍有人工边界。

BigInt/rw 与图论专项入口改按短名或唯一测试文件名寻找源文件，保留 profile 与独立参照的显式定义。学习、设计分类、覆盖含义、豁免和 README 选择仍由人维护。
