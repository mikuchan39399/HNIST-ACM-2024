## 使用边界

建议解压到 `C:\zoi\HNIST-ZOI` 等无空格固定目录。CPH 自身按空格拆参数；磁盘没有可用短路径时，带空格安装路径会在改配置前被拒绝。

卸载范围为本工具的配置、状态和未修改的受管解压包。下载 ZIP 自行删除；系统历史不在清理范围。源码仓库、自改模板、新增题解均不强删。旧安装记录或同名任务冲突会保留现场，不猜测归属。

本次没有对本机真实 VS Code 配置执行安装或卸载。
