# 线段树优化建图

区间批量连边后接最短路、可达性或 SCC。`segGraph.h`，区间下标始终指原点。

## 两棵树的方向

出树的零权边从父结点到儿子, 从某个覆盖结点能到达它表示的全部原点;
入树的零权边从儿子到父结点, 区间内原点能到达表示该区间的覆盖结点。
两树仅共用叶子编号 1 .. n, 因此骨架本身不会让不同原点互相可达。
单点连区间与区间连单点只需连 O(log n) 个覆盖结点。

区间连区间时新建一个中继点, 源区间先以零权连入, 再以 w 连向目标区间,
所以每条被压缩的逻辑边恰好贡献一次 w, 不会把两端都算成 w。
add_r2new / add_p2new 返回的中继点可继续作为单点参数连边;
区间参数始终指原点区间, 不能拿虚点编号当区间下标。

## 容量与组装

构造为 `SegGraph<W>(max_n, max_m, max_extra)`:

- max_n 是原点上限, build(n) 要求 1 <= n <= max_n; 不支持空区间或 build(0)。
- max_extra 是单轮新增中继点上限, 默认 -1 表示取 max_n。r2r、r2new、p2new 每次各用一个,
  三者次数之和不超过它。q 远大于 n 时应显式传入, 预算耗尽在新建中继点处断言。
- max_m 只是边预留提示, 可以取 0 让边数组自动增长。边容量不等于中继点容量; Graph 本身的点表不会自动增长。
- 反复 build 自动清掉旧图并恢复新增中继预算, 旧虚点编号全部失效。

build 后的骨架规模为：

$$V_0=3n-2,\qquad E_0=4n-4$$

令 $L=\max(1,\lceil\log_2 n\rceil)$，
p2p/p2new 每次 1 条边, p2r/r2p/r2new 每次至多 2L 条, r2r 每次至多 4L 条。
按各类操作次数相加即可估计 max_m, 还需另算下游算法的内存。

## 接下游算法

最短路算法应按 sg.tot 分配和初始化, 在 sg.g 上运行, 输出时通常只取 1 .. sg.n。
不能使用 sg.g.node_cnt() 代替 sg.tot: Graph 的该接口不计孤立点, n=1 且无加边时尤其明显。
非负权可接 Dijkstra, 不可达哨兵为 INF, 要求有效最短距离小于 INF 且加法不溢出。
SegGraph 自身只是建图, 负权须交给适用的最短路算法; 无权可用 SegGraph<Empty> 接可达性或 SCC,
Empty 的骨架边不能当成“走一条就加一”的原图距离。

# 单调栈

求左右最近的更大/更小元素，或给每个最值划定贡献区间。`monoStack.h` 的 `mono_stack(a,bad)` 默认求左侧最近严格较小元素的下标。

## 弹栈 → 读栈顶 → 入栈

输入 `a[1..n]`，忽略 `a[0]`；返回长度 `n+1` 的下标数组，不存在为 0。输入不变，空序列用 `{0}`。

| 弹栈条件 | 剩余栈顶表示 |
|---|---|
| `greater_equal<T>{}`：旧值 >= 新值 | 左侧最近 <，默认 |
| `greater<T>{}`：旧值 > 新值 | 左侧最近 <= |
| `less_equal<T>{}`：旧值 <= 新值 | 左侧最近 > |
| `less<T>{}`：旧值 < 新值 | 左侧最近 >= |

以最近较小为例，新值不大于旧栈顶，又离未来位置更近，因此旧栈顶可永久淘汰。比较结构体时使用固定关键字，不能随扫描改变大小关系。

`a={0,3,1,1,4}` 中，第 3 项没有左侧严格较小值，左侧最近小于等于的位置却是 2。**严格与非严格决定归属，不只是写法差异。**

## 右侧边界与区间贡献

求右侧最近位置可从 n 向 1 扫描，保留三步顺序。另一种写法是正向扫描，在弹栈时给被弹出的点填右侧答案：条件 `a[top]>a[i]` 对应右侧第一个严格较小值，不要误用 `>=`。

若 L、R 是两侧阻挡边界，i 负责的子区间数量为

$$N_i=(i-L_i)(R_i-i)$$

- 相等最值通常一侧用严格边界，另一侧用非严格边界，保证唯一归属；两侧都严格会重复计数。
- 无左边界取 0，无右边界取 $n+1$。模板“无答案”的 0 须先转换成对应边界。
- 乘法先转 `LL`，再核对贡献和的范围。

每个点入栈一次、至多出栈一次，总时间 $O(n)$，单步可弹出 $O(n)$ 个点。工作栈与返回数组约 `8(n+1)` B，不含输入。需要淘汰滑窗过期队头时用单调队列。

# 单调队列

按顺序扫描，只保留仍可能最优的候选。`monoQueue.h` 提供滑窗最值 `mono_window` 和有限前驱 DP 骨架 `mono_dp`。

## 滑窗：先入队，再取答案

`mono_window(a,k,bad)` 接收 `a[1..n]`，忽略 `a[0]`，返回下标数组 `id[0..n]`。`id[r]` 对应窗口 `[r-k+1,r]`，最值为 `a[id[r]]`；未满窗口时下标为 0，不能当合法答案读取。

| 队尾弹出条件 | 窗口答案 | 同值保留 |
|---|---|---|
| `greater_equal<T>{}`：旧值 >= 新值 | 最小值，默认 | 最右下标 |
| `greater<T>{}`：旧值 > 新值 | 最小值 | 最左下标 |
| `less_equal<T>{}`：旧值 <= 新值 | 最大值 | 最右下标 |
| `less<T>{}`：旧值 < 新值 | 最大值 | 最左下标 |

## DP：先转移，再入队

`mono_dp(cost,k)` 返回 `f[0..n]`，示范递推为

$$f_0=0,\qquad f_i=c_i+\min_{\max(0,i-k)\le j<i} f_j$$

0 是合法初态，当前 i 不能成为自己的前驱；允许负费用。`cost={0,5,-2,4,1}, k=2` 得到 `{0,5,-2,2,-1}`。若题目有不可达状态，另设无穷大并跳过无效转移，不能照抄全零初值。

## 改题时盯住三处

- **队头过期**：改左边界。窗口左端必须不后退，否则丢掉的候选无法恢复。
- **队尾淘汰**：新候选不差，且不会更早过期，旧候选才可永久删除。关键字随查询变化时须重新推导。
- **取答案时机**：窗口包含当前点就先入队；只允许严格前驱就先查询。需要恢复路径时，同时确定平手保留哪个下标。

每个点入队一次、至多出队一次，总时间 $O(n)$，单次可能弹出 $O(n)$ 个点。输入不变，各次调用无共享状态。要求 `k>=1`；`k>n` 时无完整滑窗，DP 仍有合法前驱；空序列用 `{0}`。

滑窗工作数组与返回值约 `8(n+1)` B，DP 约 `12n+16` B，不含输入；按 n 分配，并非环形 $O(k)$ 队列。所有 DP 加法须在 `LL` 内。

# 左偏树

[普通版](../../algorithms/数据结构/堆/左偏树/左偏树.cpp) 管理多个可合并堆, 接口接收逻辑元素编号;
[可持久化版](../../algorithms/数据结构/堆/左偏树/可持久化左偏树.cpp) 接收并返回物理根句柄, 由调用方保存历史版本。
两者默认小根堆, `greater<LL>` 切换大根堆。

## 普通版

`init(n,a)` 创建 n 个独立堆, a 是 1-based 初值数组, 省略则全部为零。
`merge(x,y)` 合并所属堆, `insert(x,v)` 返回新逻辑编号, x 为 0 或死点时独立成堆。
`pop(x)` 弹出所属堆顶, `erase(x)` 删除指定点; `set_val/add_val` 保留逻辑编号但消耗新物理点。
同值时较小逻辑编号优先。pop/erase 返回剩余堆顶编号, 空堆为 0, 无效死点为 -1;
merge 同堆也返回 -1。死点编号不能代替所属堆的活点继续操作。

`get_top_id/get_top_val/get_size/get_heap_sum` 查询所在堆, `get_roots_id` 返回所有堆顶编号, 顺序不固定。
编号须为当前初始化后已分配的 1..n, 0 可作为空入口; 不支持任意越界编号。

操作分两个语义域:

- 单点域可用 get_val/set_val/add_val/erase, 配合 merge/insert/pop/add_all。
- 调用 heap_add 或正数 heap_mul 后, 只用堆级操作与堆顶/大小/和查询; 非根懒标记未下传,
  不再对受影响堆调用上述单点接口。add_all 仅维护全局偏移, 不造成这个限制。

构造参数: max_n 覆盖初始逻辑点加 insert 总次数, max_ops 按 insert/set_val/add_val 次数预留;
物理表分配 max_n+max_ops, 删除不回收, init 后重新使用。LL 物理点各字段加根列表预留约 64 B,
另有 deleted 位表与逻辑点 4 B 映射; 20 万逻辑点加 10 万操作预留约 20 MB。

所属堆查找使用迭代路径压缩, 连续换根可能产生线性父链, 不承诺单次 O(log n) 或 O(α(n))。
记 h 为本次父链长度; 左偏树合并沿右链递归 O(log P), P 是累计物理点数。
惰删点在以后到达堆顶时才清理, 单次 pop/erase/set_val 可能清理多个死点, 不能按一次合并估算。
所有偏移、标记乘积、元素和及中间值都须在 T 内。

## 可持久化版

根 0 表示空堆。`new_node(v,pay)` 创建独立点, `insert/merge/pop` 返回新版本根,
旧结点不改写; empty/size/top/sum/top_pay 查询不分配结点, top/top_pay 只用于非空根。
同值时不保证 payload 的返回顺序, 要求稳定排序时由调用方把次关键字纳入键及比较器。

共享版本甚至同一个根可以 merge, 语义是多重集合相加, 重叠元素会重复出现。
逻辑元素数必须在 int 内, 元素值与求和中间值必须在 T 内; 少量物理点也可能表示巨大逻辑集合。
`init()` 清池复用容量, 之前所有根失效。

`merge_raw(x,y)` 是原地建堆接口, 两个输入都可能被修改; 只能接独占且互不重叠的堆。
建立共享版本后不得用它修改共享结点, 也不能把同一根传入两次。普通 merge 没有这些独占限制。

LL 值与 int payload 每个物理点 36 B, 构造会分配整个预算。每次 insert 额外创建单点,
merge/pop 复制 O(log N) 条路径上的结点; 预算按累计复制量计算, 固定“每操作 40 点”不是任意规模的保证。
保留历史版本会持续增加池占用；先按全部操作的复制量估预算，再乘每点字节数，另算根表。

# 并查集

| 模板 | 维护什么 | 跳板 |
|---|---|---|
| [DSU](../../algorithms/数据结构/并查集/DSU.cpp) | 集合合并、连通性、集合大小 | `dsu.h` |
| [WDSU](../../algorithms/数据结构/并查集/WDSU.cpp) | 连通性以及同组两点的有向距离或取模关系 | `wdsu.h` |

**合并方向固定**: 第二个参数所在集合的根挂到第一个参数所在集合的根。根不是最小编号, 后续合并也可能改变它。find 用两遍迭代压缩路径, 不依赖递归栈; 单次仍可能走过整条父链, 不能把它当作最坏常数时间或带按秩合并的实现。

## 普通并查集

merge(u,v) 在两组不同时合并并返回 true, 已连通时返回 false。same(u,v) 判断连通, size(x) 返回整个集合的点数。sz 只在根处有效, 不直接读取非根的 sz[x]。

```cpp
#include "dsu.h"
DSU ds(200000);
ds.init(n);                 // n 不超过构造容量
ds.merge(1, 2);
ds.merge(3, 2);             // {1,2} 的根挂到 3
int root = ds.find(1);      // 3
int count = ds.size(2);     // 3
```

集合只合并, 不拆分或删除元素。路径压缩会改写父亲, 因而不能直接把此模板当作可撤销或可持久化并查集。

## 带权并查集

用势能 P 记方向，`merge(x,y,w)` 加入关系，`query(x,y)` 返回对应差：

$$P_x-P_y=w$$

两组尚未连通时可以整体平移其中一组, 让新等式成立; 已连通时直接忽略新声明, **不检查或覆盖矛盾约束**。

d[x] 存 x 到当前父亲的距离, 根处为 0。先调用 find(x) 后, d[x] 才是 x 到当前根的距离; 不同集合的根没有共同基准, 不能直接比较其 d。

- mod=0: 保存普通有符号距离, 反向查询互为相反数。
- mod>0: 保存 [0,mod) 内的余数, 适合奇偶或分类关系。反向关系是模意义下的相反数, 不一定是普通负数; mod=1 时所有已连通关系均为 0。
- 未连通时 query 返回 WDSU::INF。合法距离也可能恰好等于 INF, 判断连通必须用 same。
- 所有距离加减中间值仍须在 LL 内; 大模数不会自动避免求和或求差溢出。

```cpp
#include "wdsu.h"
WDSU ds(200000);
ds.init(n, 3);              // 当前测试使用三类关系
long long w = 2;            // 判矛盾前先把输入归一化到 [0,3)
if (ds.same(x, y)) {
    bool conflict = ds.query(x, y) != w;
    // 调用方根据 conflict 处理矛盾
} else {
    ds.merge(x, y, w);
}
```

## 容量与复位

构造参数决定容量, 点编号为 1..n。init(n) 只重置当前有效的 0..n, 不扩容, 可以先大后小再恢复到构造容量; 默认零容量对象只能复位为 0。WDSU 的 init(n,mod) 同时清空距离并切换模式, 省略模数等价于 mod=0; 不在保留旧关系时直接改 mod。

DSU 每点约 8 字节, WDSU 每点约 12 字节, 20 万点分别约 1.6 MB 和 2.4 MB。初始化为 O(n); 查找及其封装接口按实际经过的父链长度计时, 单次最坏 O(n), 额外空间 O(1)。

# 有序表与平衡树

先分清维护的是值域集合、位置序列，还是树的拓扑。集合查询按值，序列查询按位置。

| 模板 | 语义与复杂度 | 结点预算 |
|---|---|---|
| SkipList | 去重集合, 层数匹配规模时期望 O(log n) | 峰值存活, 删除回收, K=20 每结点 176 B |
| AVL | 重复集合, 最坏 O(log n), 同值用 cnt | 累计新建, 每结点 32 B |
| Treap | 重复集合, 期望 O(log n), 同值用 cnt | 累计新建, 每结点 32 B |
| FHQ_Treap | 重复集合, 期望 O(log n), 公开值域 split/merge | 累计插入, 每结点 24 B |
| SGTree | 重复集合, 插删均摊 O(log n), 原位重建 | 峰值存活, 每结点 24 B |
| Splay | 重复集合, 访问伸展, 均摊 O(log n) | 累计插入, 每结点 24 B |
| FHQ_Seq | 按位置维护序列, 普通区间操作期望 O(log n), 批插/删除另加元素数 | 峰值存活, 每结点 96 B |
| Cartesian | O(n) 双堆型建树; build_bst 排序 O(n log n) | 图与映射按 n 分配 |

## 集合：数量与名次

集合的 get_rank(v) 返回严格小于 v 的元素数量, 不是从 1 开始的名次。
get_kth 从 1 开始, 越界返回 INF; 前驱/后继都是严格关系, 无解返回 -INF/INF。
键应在 (-INF, INF) 内。五种树 erase 返回是否删掉一个元素;
跳表 insert 返回既有或新 id, erase 返回被删 id, 无此值为 -1, 删除后 id 可能被复用。

clear 保留容量并恢复哨兵。AVL/Treap 删除不回收, 重复键只增 cnt, 预算按累计新建结点保守估算;
FHQ/Splay 每次插入各开一个结点。SGTree/SkipList/FHQ_Seq 的预算按峰值存活,
回收编号数组另占 O(预算) 空间。Treap/FHQ/Splay 的 build 输入必须升序, 且 a[0] 不参与。

## 序列：位置与标记

FHQ_Seq build 接 a[1..m], 批量 insert 接整个 vector; insert(pos) 是插入后的位置,
move_interval(l,r,pos) 是切出后放到剩余序列前 pos 个元素之后。
sum/min/max 支持全部操作; 最大子段和按非空段定义, 全负返回最大负值,
仅在建树/插删/覆盖/翻转/移动域保证有效, 加乘后不查受影响数据, 全覆盖或重建可恢复。
LLONG_MIN 哨兵不参与求和, 但所有中间和、乘法和标记叠加仍须不溢出。

## 笛卡尔树：拓扑与编号

Cartesian 的 build 用数组下标控制中序、值控制堆序, 同值保留原次序;
build_bst 用排序次序作新编号, key/orig 返回原键与插入编号, EqLeft 选择重复键往左还是往右插。
树不保证平衡, 单调数组可能生成长链; 下游遍历另考虑栈深。总点数取 ct.n,
Graph.node_cnt 不统计没有边的孤点, key/orig 仅最近调用 build_bst 后有效。

# 树状数组

[一维模板](../../algorithms/数据结构/树状数组/树状数组.cpp) 提供 BIT 区间加与前缀/区间和, BITR 通过坐标镜像提供后缀/区间和;
[二维模板](../../algorithms/数据结构/树状数组/二维树状数组.cpp) 提供 BIT2D 矩形加与矩形和。

| 接口 | 含义 | 时间 |
|---|---|---|
| BIT/BITR.add(l,r,k) | 闭区间整体加 k, 单点取 l=r | O(log n) |
| BIT.pre(x) | 1..x 之和, pre(0)=0 | O(log n) |
| BITR.suf(x) | x..n 之和, suf(n+1)=0 | O(log n) |
| BIT/BITR.query(l,r) | 闭区间和 | O(log n) |
| BIT2D.add(x1,y1,x2,y2,k) | 闭矩形整体加 k | O(log n log m) |
| BIT2D.query(x1,y1,x2,y2) | 闭矩形和 | O(log n log m) |

构造后即为指定大小的全零数组, 无需再 init。多测调用 init(n) 或 init(n,m) 清空并设置本轮范围,
每个维度分别不得超过构造容量; 可以缩小后再增大。默认构造容量为 0, 不会随 init 自动扩容。
一维复位 O(n), 二维 O(nm)。所有修改/区间查询都要求合法非空范围, 下标从 1 开始。

## 差分转区间和

令 $b_i=a_i-a_{i-1}$，前缀和满足

$$S(x)=(x+1)\sum_{i=1}^{x}b_i-\sum_{i=1}^{x}i b_i$$

一维两张表分别维护差分和差分乘下标；二维用四张表维护差分与坐标乘积项。
因此它们专用于加法与求和, 不直接支持区间赋值、最值或第 k 小。BITR 复用 BIT, 无需另维护一套实现。
负增量可用, 但增量取负、坐标乘积、表内累积、查询中间值都必须放得进 long long;
仅最终答案不溢出还不够, LLONG_MIN 不能直接作为增量。

一维每位置 16 B, 20 万约 3.2 MB; 二维每格 32 B, 2000×2000 约 128 MB,
另有边界填充和行 vector 开销。二维为稠密存储, 不适合直接分配巨大稀疏坐标域。

# 普通与动态线段树

稠密数组用 `seg.h`，大值域按需开点用 `dynamicSeg.h`。先定义 Info 的合并和 Tag 的作用，再接区间操作。
常用代数可从 [七组 Info/Tag](../../algorithms/数据结构/线段树/泛型插件/README.md) 选择；复制一组后按题改字段和作用公式。

| 场景 | 使用方式 |
|---|---|
| 已知长度的稠密数组 | SegTree(max_n), init(n) 后 build(a); 后续重建仍先 init |
| 很大值域, 初始全零 | DySegTree(n, budget), 不必 build, 按操作按需开点 |
| 动态树多测 | clear 保留值域; init(n) 清空并改值域; build(a) 自带清空并设 n=a.size()-1 |
| 静态区间最值 | [ST 表](../../algorithms/数据结构/ST表/ST表.cpp) build(a, true/false), O(1) 查询 max/min; 更新需重建 |

数组 a[0] 不参与建树; 值域与修改/查询区间必须非空, 区间合法且数值运算不溢出。
Info{} 为合并单位元, len=0; 动态版将虚区间的 len 补为真实长度后, 其余默认字段必须表示初始零值区间。
例如维护最大值时虚区间 mx=0, 合并时先判 len=0, 不能让空单位元把全负区间的最大值抬到 0。

## 标记顺序

`Tag::apply` 把新操作接到旧操作之后。仿射操作先做 $ax+b$，再做 $cx+d$，合成后为

$$x\mapsto (ca)x+(cb+d)$$

赋值与加法不能随意交换。
普通懒标记提供恒 false 的 break_cond 和恒 true 的 tag_cond;
势能修改由前者判无需修改, 后者判整段可施加标记, 叶子必须能终止。
可选 get_real_tag 将修改请求转成实际懒标记, split_tag 负责向左右孩子分发。
局部等差标记跨查询端点的偏移仍由代数层负责, 引擎不会自动把每个覆盖段换算为修改左端点。

## 找位置

find_first(start, pred) 与 find_last(end, pred) 找的是符合条件的点。
pred 必须等价于“这段里存在答案”, 例如 mx >= k; 区间和 >= k 不具有一般的存在性含义,
也不会在遍历中累积前缀。找不到或 start/end 不在 [1, n] 内返回 -1。

## 开点与复位

动态池按两次复位之间的累计开点数预算, 不按操作数直接当结点数。
build 使用 2n-1 个实结点; 普通懒修改、查询和查找每次可能新增 O(log n) 个,
势能修改按实际访问和开点分析。查询并非只读: 下传旧标记时也可能创建子结点。
复位保留容量并恢复 0 号哨兵, 旧结点编号失效。40 B/结点时 400 万预算约 160 MB。

# 主席树

PersSegTree 的根由调用方保存。modify(old_root,l,r,tag) 返回新根, 旧版本仍可查询或继续分叉;
根 0 表示全零初始树。

| 接口 | 约定 |
|---|---|
| build(a) | a[1..m] 非空, 返回新基线根并把 n 设为 m; 追加到池中, 不清旧版本 |
| modify | 单点传 l=r, 只支持加法类可交换标记 |
| query/find | 不开结点, 查询累积祖先标记; 加法可维护 sum/max 等相容 Info |
| find_kth(plus,minus,k) | 多根计数相加减, 返回值域下标; 仅点修改计数版本 |
| clear | 清空全部版本并恢复哨兵, 保留容量与 n, 旧根全部失效 |
| set_n | 只改值域, 不清池; 改成不同值域后不能再访问旧域根 |

所有根都按当前 [1,n] 解释。多次 build 可以保留同值域的多个基线;
如果长度改变, 旧根不能拿到新值域里查询。多测通常先 clear, 再 set_n 或 build。

Info{} 的 len=0 表示合并单位元, 补上虚区间真实长度后其余字段须表示初始零值区间。
Tag 的叠加须满足本引擎的永久化契约, Info.apply 与合并须相容;
区间赋值等有顺序依赖的标记不适用。所有数值与中间运算仍须不溢出。

find_first/last 的 pred 要等价于“区间里存在合格点”, 例如 mx>=k。
若用 cnt>0, 必须保证逐点计数非负; 接口不会累计前缀。

find_kth 要求相加减后**每个位置**计数非负, 并且 1<=k<=总计数, 只有总计数非负不够。
范围加版本不能直接拿来做 kth, 因为 kth 不累积内部永久标记。

## 版本计数与预算

区间第 k 小用前缀版本相减：

$$H_{[l,r]}=H_r-H_{l-1}$$

树上点路径用根到点的计数版本。令 $p=\operatorname{lca}(u,v)$：

$$H_{u,v}=H_u+H_v-H_p-H_{\operatorname{parent}(p)}$$

根的父亲取空版本。各位置计数须非负，k 在总计数范围内。

预算按累计复制结点计算，查询和 find 不开点。点修改每次复制一条根到叶的路径；先开满一棵树需 $2n-1$ 个结点。区间修改按实际覆盖与复制量估算，不能直接套点修改预算。计数结点常为 32 B，sum/max 代数常为 40 B，另算根表与容量预留。
