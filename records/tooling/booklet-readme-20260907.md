## 恢复逐实现预留与源码目录

用户指出左偏树层级遗漏、平衡树没有实现目录，原有排版预留被遗忘，并要求撤掉短句。检查确认 `堆/左偏树/` 是正常家族层级，两版源码均已打印；八份有序表与平衡树实现也在正文。遗漏来自源码标题的 `outlined: false`，而拥挤来自此前把逐实现起页改成方向内连续排版。旧生成器在默认 SoloMin=0 时也逐实现另起页，SoloMin 只是额外要求奇数页。

本轮决定与实现：

- 家族目录允许直接并列实现，独立子算法或各自说明需要时才建子目录；不为目录显示给每文件增添空层。本轮没有搬动源码或改变 include。目录同时显示实际文件夹和具体代码/登记笔记/插件，仅唯一源码与目录同名时合用标题。
- 恢复每个实现独立起页，长模板与紧随的说明自动续页，该页段剩余区域留作补写，后续实现和待建目录不占用。目录标题先缓冲，随首个实现或空叶一起输出，避免父标题被换页留在前页。待建目录另起一段集中排，短线后留间距；方向起新页。页眉优先显示实现名，续页延用，待建页显示分类。
- 删除短题记数据文件、发现及渲染逻辑、九份分类明细家族引言；保留三类标准和全部 213 项归类。rule、算法入口、功能表、打印/维护/测试指南同步，明确不得为压缩页数取消补写预留。
